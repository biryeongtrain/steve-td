# 히어로 빌더

히어로 빌더는 공격 가능한 여우 한 마리와, 웨이브마다 적으로 변하는 숙적을 함께 운용합니다. 직업 ID는 `semion-td:adversary_towers`입니다.

## 플레이 흐름

1. 히어로 여우를 한 마리 설치합니다.
2. 브리즈, 크리퍼, 팬텀, 북극곰 숙적을 설치합니다.
3. 웨이브가 시작되면 숙적이 설치 위치에서 보상 0의 적 몬스터로 변합니다.
4. 여우가 숙적에 막타를 내면 해당 숙적 타워의 기여 점수가 오릅니다.
5. 준비 단계에서 레시피가 완성되면 여우가 처음부터 공개된 네 중간 루트와 여덟 최종 형태 중 하나로 진화합니다.

숙적은 타워 슬롯을 사용하며 개수 제한은 별도로 없습니다. 소스 기본값에서 일반 숙적은 처치당 1점, 강화 숙적은 2점을 제공합니다. 숙적을 판매하면 해당 개체가 지금까지 제공한 점수도 사라지고 환불은 없습니다.

## 여우 형태

여우는 별도 업그레이드 타워로 교체되지 않습니다. 하나의 논리 타워 안에서 `기본 1 + 중간 4 + 최종 8` 형태를 유지하며, 현재 형태는 입에 든 아이템과 타워 상세 정보에 표시됩니다.

| 루트 | 중간 형태 | 최종 분기 |
|---|---|---|
| 빠른 저비용 | 질풍 여우 | 황금 송곳니 / 방패 투사 |
| 팀 지원 | 종지기 여우 | 봉화지기 / 불길한 주술사 |
| 대상 특화 | 추적자 여우 | 폭죽 관통수 / 거물 추적자 |
| 느린 초고점 | 메아리 여우 | 천벌의 집행자 / 스컬크 재앙핵 |

형태가 바뀔 때 현재 체력 비율과 일반 공격 쿨다운은 유지됩니다. 추가타 횟수, 집중 공격, 예약 폭발 같은 형태 전용 임시 상태는 초기화됩니다.

## 공개된 전직 레시피

모든 중간·최종 형태의 조건은 게임 시작부터 타워 상세 정보와 `/직업` 설명에서 확인할 수 있습니다. 숨겨진 최종형이나 별도 인컴 지름길은 없으며, 전직은 설치한 숙적을 **여우가 직접 막타**해 쌓은 점수로만 판정합니다.

| 루트 | 중간 형태 조건 | 최종 형태 조건 |
|---|---|---|
| 빠른 저비용 | 브리즈 12점 → 질풍 여우 | 황금 송곳니: 브리즈 50점 / 방패 투사: 브리즈 30점 + 북극곰 20점 |
| 팀 지원 | 팬텀 14점 → 종지기 여우 | 봉화지기: 팬텀 50점 + 북극곰 25점 / 불길한 주술사: 팬텀 50점 + 크리퍼 30점 |
| 대상 특화 | 크리퍼 16점 → 추적자 여우 | 폭죽 관통수: 크리퍼 60점 + 브리즈 30점 / 거물 추적자: 크리퍼 60점 + 북극곰 30점 |
| 느린 초고점 | 북극곰 18점 → 메아리 여우 | 천벌의 집행자: 북극곰 80점 + 브리즈 40점 / 스컬크 재앙핵: 북극곰 100점 + 팬텀 50점 + 크리퍼 40점 |

SemionTD가 최대 체력 1024 제한을 직접 해제하므로 별도의 AttributeFix가 필요하지 않습니다. 여우 런타임의 논리 체력 버퍼도 호환 경로로 유지합니다.

## 진화 규칙

- 처음 완성한 중간 레시피가 주 루트를 잠급니다.
- 중간 형태로 최소 한 웨이브를 치른 뒤부터 최종 레시피를 판정합니다.
- 한 준비 단계에는 한 단계만 진화합니다.
- 숙적 판매로 점수가 부족해지면 최종에서 중간, 중간에서 기본 순서로 강등됩니다.
- 강등되어도 이미 선택한 주 루트와 최종 분기 잠금은 유지됩니다.
- 스컬크 재앙핵을 포함한 모든 최종 형태의 점수 레시피는 처음부터 상세 정보에 공개됩니다.

인컴 몬스터 처치는 진화 점수나 루트에 영향을 주지 않습니다. 진화는 설치한 숙적의 누적 점수로만 결정됩니다.

기본 여우는 체력 300, 피해 16/10tick으로 초반 전투력이 제한됩니다. 종지기와 불길한 주술사는 다친 여우 한 기를, 봉화지기는 다친 여우 최대 두 기를 회복합니다. 천벌의 집행자는 적중 시 주변 최대 8기에게 25% 휩쓸기 피해를 주며, 스컬크 재앙핵의 자해는 최대 체력 40% 아래로 체력을 낮추지 않습니다.

강화 숙적은 같은 가격의 강화 비용으로 점수만 2배가 되는 대상이 아닙니다. 일반 숙적보다 체력 2.25배, 공격력 1.70배, 방어 +4, 사거리 +0.5블록이며 공격 간격도 20% 짧습니다. 따라서 강화는 전직 속도를 높이는 대신 여우에게 확실히 더 위험한 투자입니다.

## 설정과 런타임

여우 기본 배치 타입과 숙적의 가격·전투 수치는 `tower_balance.json`의 `towers`에서 관리합니다. 여우 13형태의 체력·사거리·피해·공격 간격, 진화 요구량과 고유 공격·버프·디버프는 `abilities`에서 관리합니다. 숙적 강화 가격은 `upgradeCosts`에 있습니다. 누락된 값은 서버 기본값으로 보충되며 `/semiontd reload`로 새 카탈로그에 반영됩니다.

숙적의 바닐라 엔티티 외형만 사용하며, 크리퍼 폭발이나 팬텀 비행 같은 바닐라 고유 AI는 사용하지 않습니다. 스컬크 폭발만 마법 피해이고 나머지 기본 및 특수 공격은 물리 피해입니다.

회복은 반경 안에 있는 같은 소유자의 살아 있는 다른 여우만 대상으로 하며, 체력 비율이 낮은 순서로 적용됩니다. 불길한 주술사의 약화 효과는 같은 팀의 라인을 공격하는 일반 몬스터에게 적용되며 숙적은 제외됩니다.

## 확인 방법

- `/직업` 또는 `/semiontd job ui`에서 히어로 빌더를 선택합니다.
- `/semiontd tower list`에서 여우와 일반 숙적 네 종류만 starter로 보이는지 확인합니다.
- 숙적 강화, 웨이브 변환·복귀, 점수 증가와 판매 강등은 타워 상세 정보와 실제 웨이브에서 확인합니다.
