# 빌더와 타워

이 문서는 현재 코드에 등록된 빌더와 타워 계열을 정리합니다. 기준 코드는 `JobRegistry`와 `ProductionTowerCatalogs.reloadBuiltIns(...)`입니다. 타워 수치, 특수 효과, 등록 API는 [프로덕션 타워 카탈로그](production-tower-catalog.ko.md)를 봅니다.

|---|---|---|---|

| `semion-td:villager_towers` | 주민 빌더 | 타워를 오래 살리고 업그레이드해 누적 보너스를 받습니다. | 주민 |
| `semion-td:villager_adv_towers` | 주민 ADV 빌더 | 경험치와 평판을 쓰는 주민 리워크 계열입니다. | 주민 ADV |

## 타워 계열

### 주민

- 직업 ID: `semion-td:villager_towers`
- 표시명: 주민 빌더
- 흐름:
  - 주민 원거리 기본 타워 -> 사서 타워 -> 성직자 타워
  - 눈 골렘 타워 -> 라마 타워 -> 철 골렘 타워
  - 알레이 타워 -> 알레이 타워(강함) -> 갑옷 제조인 타워
  - 알레이 타워 -> 대장장이 타워 -> 강화 대장장이 타워
  - 오셸롯 타워 -> 저격 캣 타워 -> 강화 저격 캣 타워
  - 오셸롯 타워 -> 라클 캣 타워 -> 강화 라클 캣 타워

### 주민 ADV

- 직업 ID: `semion-td:villager_adv_towers`
- 표시명: 주민 ADV 빌더
- 흐름: 주민 빌더와 비슷한 분기 구조를 쓰지만 별도 타워 ID를 가진 별개 빌더입니다. 타워 ID에는 `villager_adv_` prefix가 붙습니다.
- 자원: 각 타워는 경험치를 사용하고, 빌더 전체는 평판 보너스를 받습니다.

### 언데드

- 직업 ID: `semion-td:undead_towers`
- 표시명: 언데드 빌더
- 흐름:
  - 좀비 타워 -> 허스크 타워 -> 드라운드 타워
  - 뼈 타워 -> 보그드 타워 -> 스트레이 타워
  - 뼈 타워 -> 위더 스켈레톤 타워 -> 강화 위더 스켈레톤 타워
  - 좀비 말 타워 -> 스켈 말 타워

### 동물

- 직업 ID: `semion-td:animal_towers`
- 표시명: 동물 빌더
- 흐름:
  - 돼지 타워 -> 돼지 타워 -> 돼지 타워
  - 늑구 타워 -> 재빠른 늑구 타워 -> 개빠른 늑구 타워
  - 토끼 타워 -> 토끼 타워 -> 토끼 타워
  - 사냥 여우 타워 -> 붉은 여우 타워 -> 설원 여우 타워

### 흑마법사

- 직업 ID: `semion-td:warlock_towers`
- 표시명: 흑마법사
- 흐름:
  - 흑마법사 기본 타워 -> 원거리 흑마법사 타워
  - 흑마법사 기본 타워 -> 근접 흑마법사 타워
  - 희생 타워 -> 희생"양" -> 희생"양"
  - 애완 개구리 -> 애완 개구리 -> 애완 개구리
- 제한: 흑마법사 코어는 한 라인에 하나만 둘 수 있습니다.

### 무리

- 직업 ID: `semion-td:legion_towers`
- 표시명: 무리 빌더
- 흐름:
  - 닭 계열 -> 인싸 닭 타워 또는 아찐 닭 타워
  - 슬라임 계열 -> 슬라임 타워
  - 펭귄 계열 -> 강화 땡컨타워
  - 앵무 계열 -> 앵무 타워
  - 염소 계열 -> 짱쌘 염소 타워 -> 개쌘 염소 타워
  - 환영 타워는 별도 starter로 등록됩니다.
- 참고: 벌 계열은 `TowerBalanceConfig` 기본값에 수치가 있지만 현재 카탈로그 등록 코드는 비활성 주석 상태입니다.

### 무블룸

- 직업 ID: `semion-td:resonance_towers`
- 표시명: 무블룸 빌더
- 흐름:
  - 집속: Focus Crystal -> 해바라기 집속 무블룸 -> 주황 튤립 초점 무블룸
  - 파동: Wave Crystal -> 파란 난초 진동 무블룸 -> 푸른 들꽃 파동 무블룸
  - 서리: Frost Crystal -> 하얀 튤립 서리 무블룸 -> 데이지 빙결 무블룸
  - 증폭: Amplify Crystal -> 라일락 정원 무블룸 -> 작약 공명 무블룸
- 조건: 다른 종의 무블룸을 1칸 안에 모으면 공명 단계가 올라갑니다.

### 우민

- 직업 ID: `semion-td:illager_towers`
- 표시명: 우민 빌더
- 흐름:
  - 변명자 타워 -> 변명자 대장타워 -> 파괴수타워
  - 약탈자 타워 -> 약탈자 대장타워(단일) -> 소환사타워(단일)
  - 약탈자 타워 -> 약탈자 대장타워(광역) -> 소환사타워(광역)
  - 벡스 타워 -> 마녀타워(약자 표식) -> 환술사타워(약자 표식)
  - 벡스 타워 -> 마녀타워(강자 표식) -> 환술사타워(강자 표식)
- 자원: 웨이브 처치, 인컴 처치, 표식 처치, 우민 타워 사망으로 습격 게이지를 얻습니다.

### 대적자

- 직업 ID: `semion-td:adversary_towers`
- 표시명: 히어로 빌더
- 흐름: 공격 가능한 여우 한 마리와 브리즈·크리퍼·팬텀·북극곰 숙적을 설치합니다. 숙적은 웨이브 시작 시 설치 위치에서 적으로 변하고 다음 준비 단계에 타워로 돌아옵니다.
- 성장: 여우가 숙적에 막타를 내 얻은 점수로 처음부터 공개된 빠른 저비용, 팀 지원, 대상 특화, 느린 초고점의 네 루트와 여덟 최종 형태의 전직 조건을 충족합니다.
- 참고: 상세 레시피와 전직 규칙은 [히어로 빌더](adversary-builder.ko.md)를 봅니다. 인컴 처치는 전직에 영향을 주지 않습니다.

### 용사 파티

- 직업 ID: `semion-td:hero_party`
- 표시명: 용사 빌더
- 흐름: 용사를 먼저 설치한 뒤 기사·궁수·마법사·사제·도적·음유시인 중 네 종류를 확정합니다. 동료 선택은 판매해도 해당 경기 동안 유지됩니다.
- 성장: 준비 단계의 용사 상점에서 무기와 갑옷을 구매·강화하고, 웨이브 퀘스트 보상으로 파티 전체의 공격·회복·체력을 높입니다.
- 타워 수: 용사는 3, 동료는 T1~T4에서 2/3/4/5를 사용해 최종 파티가 23을 사용합니다.

### 식물

- 직업 ID: `semion-td:plant_towers`
- 표시명: 식물 빌더
- 구조: **테라포밍 타워**와 **전투 타워**가 분리돼 있습니다. 테라포밍 타워는 공격하지 않고 지형만 깔며,
  전투 타워는 자기 계열 지형 위에만 심을 수 있습니다.
- 공통: 모든 식물은 뿌리를 내려 **레인 안에서 사거리 밖 대상을 쫓아 이동하지 않습니다**
  (`Tower.canChaseTargets()` false).
- 한 칸은 한 계열만 가질 수 있어 다른 계열 지형 위에는 심지 못합니다.
- **지형 선점은 영구입니다.** 이미 깔린 칸은 어떤 계열도 다시 바꾸지 못합니다. 테라포머 반경이 남의
  지형에 걸치면 그 칸만 건너뛰고 빈 칸만 변환합니다.
- **테라포밍 타워를 팔면 그 타워가 만든 칸이 원래 블록으로 되돌아갑니다.** 각 칸은 자기를 만든
  테라포머와 이전 블록을 기억합니다. 이게 없으면 설치 → 환불 → 한 칸 옆에 재설치를 반복해 라인 전체를
  헐값에 덮을 수 있습니다. 테라포밍 타워는 무적이라 파괴로는 지형을 잃지 않습니다.
- 업그레이드는 `replaceTower` 가 제거 직후 새 타워를 배치하므로, 되돌아간 칸이 넓어진 반경으로 다시
  깔립니다.

| 계열 | 지형 | 테라포밍 타워 (T1 → T2 → T3) | 전투 타워 (T1 → T2 → T3) | 역할 |
|---|---|---|---|---|
| 참나무 | 잔디 | 참나무 묘목 → 자란 참나무 묘목 → 짙은 참나무 묘목 | 민들레 → 데이지 → 해바라기 / 빨간 튤립 → 양귀비 → 횃불꽃 | 지원·광역 |
| 갈색 버섯 | 균사 | 갈색 버섯 → 자란 갈색 버섯 → 포자 군체 | 붉은 버섯 → 진홍빛 버섯 → 뒤틀린 버섯 | 라운드당 1회 지뢰 |
| 마른 풀 | 사암 | 마른 풀 → 자란 마른 풀 → 마른 풀 군락 | 죽은 덤불 → 선인장 → 꽃선인장 | 반사 탱커 |
| 가문비나무 | 회백토 | 가문비나무 묘목 → 자란 가문비나무 묘목 → 가문비 묘상 | 고사리 → 큰 고사리 → 세 갈래 분기 | 딜러 |

- 잔디 계열은 전투 라인이 둘입니다. 지형 효과(회복·성장 분배)는 두 라인 모두 받습니다.

| 라인 | 성격 | 특징 |
|---|---|---|
| 민들레 → 데이지 → 해바라기 | 경제·지원 | 팀이 웨이브를 마치면 살아 있고 잔디 위에 있는 타워마다 **다이아를 4/11/28개** 정산합니다. 어그로가 30~40으로 낮아 뒤에 섭니다. |
| 빨간 튤립 → 양귀비 → 횃불꽃 | 자기 중심 광역 | 공격할 때 타워 자신을 중심으로 반경 4.0~5.5를 함께 때립니다. 주 대상은 중복 피해를 받지 않습니다. |

- 다이아당 체력은 `고사리 계열 < 잔디 계열 < 사암 계열` 순서를 지킵니다. 잔디 계열은 서로
  회복까지 하므로 기본 체력이 탱커와 비슷하기만 해도 실제 내구력은 더 높아집니다. 그러면
  앞에서 맞아 주는 사암을 세울 이유가 없어집니다.
- 어그로 순서는 `민들레(30~40) < 튤립(45~60) < 모래(58~74)`입니다. 탱킹은 모래가 전담하고 튤립은
  적 근처에 서되 먼저 물리지는 않습니다.

- 회백토 계열만 T2 `큰 고사리`에서 최종 형태가 세 갈래로 갈라집니다.

| 최종 형태 | 성격 | 특징 |
|---|---|---|
| 라일락 | 근거리 광역 | 사거리 14. 공격마다 반경 5.0의 130도 부채꼴로 35% 꽃잎 피해를 줍니다. 단일 피해가 가장 낮습니다. |
| 장미 덤불 | 단일 극딜 | 사거리 16, 피해 46, 간격 16틱. 단일 화력이 가장 높습니다. |
| 물병 식물 | 곡사 포대 | 사거리 30으로 라인 전체를 덮고 착탄 반경 4.0에 45% 포격 피해가 퍼집니다. 간격 45틱으로 가장 느립니다. |

- 식물은 못 움직이므로 사거리 감소 디버프에 특히 취약합니다. 그래서 전 계열 사거리를 다른 빌더보다
  넉넉하게(대략 2배) 잡아 뒀습니다.
  - 민들레 계열(8/10/12 → **11/13/16**): 어그로가 가장 낮아 뒤에 서는데, 사거리가 짧으면 뒤에 선
    채로는 아무것도 못 합니다.
  - 고사리 계열(고사리 12 → **16**, 큰 고사리 14 → **18**, 라일락 14 → **18**, 장미 덤불 16 → **20**):
    딜러인데 사거리가 짧으면 맞아 가며 쏴야 합니다.
  - 물병 식물 30은 그대로입니다. 장미 덤불(20)의 정확히 1.5배로, "라인 전체를 덮는 곡사 포대"
    라는 역할을 지키는 하한입니다 — 장미 덤불을 더 올리려면 물병 식물도 같이 올려야 합니다.
  - 튤립 계열은 올리지 않았습니다. 자기 중심 광역이라 붙어서 싸우는 역할이고, 여기까지 늘리면
    근접 광역이라는 구분이 사라집니다.

- 꽃선인장(모래 T3)은 선인장 위에 선인장꽃을 얹은 2단 block display입니다.
  `BlockDisplayVisual.topBlockState(...)`로 상단 블록을 지정합니다.
- **테라포밍 타워는 무적이고 어그로를 끌지 않습니다.** 공격을 못 하는 설비라 몬스터가 아예 무시하고
  어떤 피해도 받지 않습니다 (`Tower.invulnerable()`, `Tower.drawsAggro()`).
- **환경 효과**: 타워 없이 지형만으로 그 위에 선 적에게 걸립니다. 타워 오라와 별개입니다.

| 지형 | 환경 효과 |
|---|---|
| 균사 | 약화 (적 공격력 감소) + 취약 (받는 타워 피해 증가) + **이동 속도 감소** |
| 사암 | **공격 속도 감소** + 최대 체력 비례 지속 피해 (초당 0.5%) |
| 잔디·회백토 | 없음 (아군 지형) |

- 테라포밍 반경은 티어에 비례합니다. T1은 반경 1칸(3×3), T2는 반경 2칸(5×5), T3는 반경 3칸(7×7)입니다.
- 지형 효과
  - 잔디: 주변 아군 타워를 주기적으로 회복시킵니다(반경 `supportRadius`).
    **한 대상을 여러 잔디가 함께 회복시키면 두 번째부터 50% 만 들어갑니다**
    (`meadowHealOverlapReduction`). 겹치기를 막지는 않지만 잔디 개수만큼 회복이 곱절로
    늘어나지는 않습니다.
    성장 체력 분배는 거리 제한이 없습니다. **라인의 모든 잔디 타워가 쌓은 성장치의 20%를 합산해
    라인 안 모든 타워에게 같은 값으로** 최대 체력 버프를 겁니다. 합산 보너스는 50%가 상한입니다.
  - 균사: 전투 타워가 **지뢰**라 상주 화력이 없으므로, 취약(딜증)과 약화를 지형이 직접 겁니다.
    지뢰는 적이 `triggerRadius` 안에 들어오면 터져 범위 피해와 둔화를 주고, 공격 속도·공격력을
    100% 깎아 몇 초간 공격을 무력화합니다.
    적이 `triggerRadius` 안에 들어오면 즉발이 아니라 **섬광 파티클이 한 번 뜨고 `fuseTicks` 뒤에**
    터집니다. 폭발 판정은 터지는 시점에 다시 잡으므로 도화선이 타는 동안 빠져나간 적은 맞지
    않습니다. 점화된 뒤에는 적이 사라져도 취소하지 않습니다 — 취소를 허용하면 스치듯 지나가며
    무료로 예열해 두는 짓이 가능해집니다.
    **한 라운드에 한 번만 터집니다.** 터진 뒤에는 그 라운드 동안 빈 껍데기로 남고, 라운드가 끝나면
    한 단계씩 삭아 내려갑니다(뒤틀린 → 진홍빛 → 붉은). 붉은 버섯은 사라집니다. 소모 단위가 폭발
    한 번에서 라운드 하나로 옮겨간 것이라, 뒤틀린 버섯을 심으면 세 라운드에 걸쳐 세 번 씁니다.
    라운드 안에서 다시 장전하게 두면 지뢰 하나가 광역 기관총이 되고, 무력화 시간이 재장전보다
    길면 그 길목의 적은 영영 공격하지 못합니다. 라운드당 한 번이면 그 두 가지를 값 조정 없이
    구조로 막습니다.
    **몬스터는 지뢰를 표적으로 삼지 않습니다**(`drawsAggro` false). 라운드 내내 남게 된 이상
    어그로를 끌면 지뢰가 사암 탱커보다 싼 고기방패가 됩니다 — 붉은 버섯은 30다이아에 체력 110으로
    죽은 덤불보다 다이아당 체력이 높습니다. 무적은 아니라서 광역 피해로는 깎이고, 깎이면 폭발도
    약해집니다.
    삭히는 처리는 `PlantTowerJob.onRoundEnded`가 맡습니다 — 라운드 경계를 아는 쪽은 타워가 아니라
    직업이고, `PlayerLane.resetForRound`는 타워 목록을 그대로 순회해 그 안에서 갈아 끼울 수 없습니다.
  - 사암: 전투 타워가 **스스로 공격하지 않습니다**(사거리 0). 대신 맞을 때마다
    `받은 피해 × thornReflectRatio + 자기 공격력`을 반사하고, 이 반사는 개화·취약 배율을 그대로 탑니다.
    **반사는 때린 그 적 하나에게만 갑니다. 광역이 아닙니다.**
    뒤의 고정항(자기 공격력)은 맞은 크기와 무관하게 매 타격마다 나가므로, 값싼 탱커를 스무 개
    깔면 그만큼의 독립된 딜러가 됩니다. 체력만 깎아서는 도배가 계속 통했던 이유가 여기입니다.
    그래서 고정항을 **다이아당으로는 상위 티어가 더 높도록**(T1 2 / T2 10 / T3 20) 잡아,
    도배보다 올리는 쪽이 낫게 유지합니다. 아예 없애지는 않습니다 — 없애면 작은 공격에는 반사가
    사실상 사라져 계열의 역할이 무너집니다.
    사암 전투 타워는 주변 사암 위의 적에게 지형 자체보다 강한 공격 속도 감소를 겁니다(0.25 vs 0.15,
    겹치면 큰 쪽 적용). 사거리가 0이라 장판 반경은 `plant_soil_desert.auraRadius`가 정합니다.
    적 이동 속도 감소는 사암이 아니라 **균사**가 담당합니다.
    지형 블록으로 모래를 쓰면 레인 바닥이 1칸일 때 중력으로 떨어져 사라지므로 사암을 씁니다.
    `PlantSoil`에는 `FallingBlock`을 넣지 않습니다.
  - 회백토: 사거리와 공격 속도를 얻습니다.
- 개화: 전투 타워는 자기 계열 지형 칸 수에 비례해 피해가 증가하며 `bloomDamageCap`에서 멈춥니다.
- 딜증 상한: 개화(최대 +40%)와 균사 취약(+25%)이 곱연산으로 붙어 최대 +75%입니다.
- 기본 피해는 모든 티어에서 50 이하이며(최대 46, 침엽 거목), 화력은 지형 배율에서 나옵니다.
- 지형 수치는 `tower_balance.json`의 `plant_soil_meadow`, `plant_soil_mycelium`, `plant_soil_desert`,
  `plant_soil_podzol`, `plant_global`에 있습니다. 티어별 배율은 각 전투 타워의 `soilPower`입니다.
### 람쥐썬더

- 직업 ID: `semion-td:thunder`
- 표시명: 람쥐썬더 빌더
- 흐름:
  - 피뢰침 -> 구리 피뢰탑(안정 출력)
  - 피뢰침 -> 폭풍 유도침(변동 출력)
  - 꼬마 아르마딜로 -> 절연 아르마딜로 -> 고무 아르마딜로
  - 꼬마 아르마딜로 -> 접지 아르마딜로 -> 대지 아르마딜로
  - 아기 람쥐 -> 람쥐썬더 -> 뇌신 람쥐썬더
  - 아기 람쥐 -> 폭주 람쥐 -> 과부하 람쥐
- 자원: 전력. `가동률 = 총 소비 / 총 발전`이며 발전에는 기본 전력 80이 항상 포함됩니다. 가동률이 낮으면 전력 여유로 공격력이 오르고, 1.0을 넘으면 전력 부족으로 공격력과 공격 속도가 함께 떨어집니다.
- 전력이 충분하면 공격력이 최대 22% 증가합니다. 파괴된 타워는 발전과 소비에서 즉시 제외됩니다.
- 기본 전력이 있는 이유: 라인 슬롯은 5개에서 시작합니다. 기본 공급이 없으면 이 빌더만 초반 슬롯을 공격하지 못하는 타워에 써야 합니다. 발전 타워는 소비가 큰 상위 티어를 굴리기 위한 확장입니다.
- 절연 루트는 전력을 소비하지 않아 전력 부족의 영향을 받지 않고, 잃은 체력에 비례해 발전에 기여합니다. 접지 루트는 전력을 소비하는 대신 공격한 적에게 표식을 남겨 아군 전체의 피해를 키웁니다.
- 아르마딜로의 감전은 1초간 적을 멈추며, 같은 플레이어의 감전에는 이후 2.5초간 면역이 생깁니다.
- 폭풍 유도침은 웨이브마다 출력이 달라지며 `stormWaveInterval` 웨이브마다 최대 출력이 확정됩니다. 롤은 플레이어 단위로 공유되므로 같은 웨이브에서는 모든 폭풍 유도침이 같은 출력을 냅니다.
- 시각 구분: 발전은 블록 디스플레이(피뢰침), 탱커는 아르마딜로, 딜러만 Blockbench 다람쥐 모델을 씁니다. 폭주 계열은 같은 T1에서 갈라져 나란히 설 수 있으므로 푸른색 변형 모델을 씁니다.
- 광역 연출: 계열 전용 VFX 두 종을 씁니다. `semion-td:thunder_arc`는 뇌신의 전이를 맞은 적에서 뻗어나가는 번개로 그리고, `semion-td:thunder_discharge`는 대지 아르마딜로의 방전을 죽은 자리에서 솟는 번개로 그립니다. 정의는 `ThunderVfx`에 있습니다.
- 타워 상세 정보에는 발전/소비/가동률과 함께 현재 공격력·공격 속도 증감이 표시되며, 폭풍 유도침은 이번 웨이브 출력과 다음 뇌우까지 남은 웨이브를 함께 보여줍니다.

### 군대

- 직업 ID: `semion-td:army`
- 표시명: 군대 빌더
- 흐름:
  - 행정병 -> 조교(진급 가속) 또는 보급관(수확 특화)
  - 위병 -> 헌병 -> 헌병대장
  - 위병 -> GOP 초병 -> 초소장
  - 훈련병 -> 특급전사 -> 소대장
  - 훈련병 -> 포병 -> 포대장
- 자원: 짬. 전투 타워는 웨이브 시작에 이번 증가량을 정하고, 살아남으면 라운드 종료 뒤 짬을 얻습니다.
  짬에 따라 계급이 오르며, 계급이 오르면 공격력이 줄고 대신 반경 안의 **더 낮은 계급** 아군을 강화합니다.

| 계급 | 짬 | 공격력 | 후임 버프 |
|---|---|---|---|
| 이등병 | 0~1 | ×1.00 | 없음 |
| 일병 | 2~4 | ×0.75 | 공격력 +12% |
| 상병 | 5~8 | ×0.40 | +28% |
| 병장 | 9~12 | ×0.00 | +50%, 공속 +15% |

- **티어와 계급은 직교합니다.** 티어는 미네랄로 사고 기본 스탯을 정하며, 계급은 시간으로 얻고
  그 기본 스탯 중 얼마를 실제로 쏘는지를 정합니다. 업그레이드해도 계급은 유지됩니다
  (`ArmyTower.copyRuntimeStateFrom`).
- **표기 공격력은 이등병 기준입니다.** 짬 0~12 구간의 평균 배율은 `0.45`이며, 계열 스탯은 이 값을
  전제로 일반 딜러 곡선(효율 20~26)에 맞춰 잡았습니다. 계급 곡선을 바꾸면 전투 계열 스탯을 다시
  계산해야 합니다 (`ArmyRankTest.lifetimeAverageAttackMultiplierIsFortyFivePercent`).
- 고참 1기는 후임 2기부터 이득입니다. 모든 계급의 손익분기가 약 2기가 되도록 맞춰져 있어
  자연스럽게 1:2 피라미드가 강제됩니다. 버프 합산 상한은 `maxCommandBonus`(+120%)입니다.
- 짬 13에 **자동 전역**합니다. 전역하면 매입가의 90%를 돌려받고 **훈장**이 남아 라인 전체 공격력이
  영구히 오릅니다(개당 +2%, 최대 10개). 보급관 1기는 돌려받지 못한 10% 중 40%를 회복해 전역금을
  94%로 만들며, 여러 기를 쌓아도 100%를 넘지 않습니다. 이 빌더의 장기 성장은 타워를 키우는 것이
  아니라 몇 명을 제대로 전역시켰느냐입니다.
- 전역 2웨이브 전부터 타워 상세 정보에 예고가 뜹니다.
- 조교(+2)와 초소장(-2)은 같은 손잡이를 반대로 돌린 것이라 함께 두면 상쇄됩니다. 조교는 회전을
  빠르게 돌려 훈장을 모으고, 초소장은 효율이 가장 좋은 상병 구간에 오래 머무르게 합니다.
- **경계 계열은 계급 체계 밖에 있습니다.** 계급이 올라도 공격력이 줄지 않고 후임을 강화하지도
  않습니다. 앞라인이 짬 때문에 무력해지면 라인이 그냥 뚫리기 때문입니다.
- 계급 체계는 티어별로 다릅니다. T1 은 병사(이등병~병장), T2 는 부사관(하사~원사), T3 는
  장교(소위~소령)입니다. 수치는 세 체계가 완전히 동일하고 호칭만 다릅니다 — 소대장이 이등병으로
  불리면 버그로 읽히기 때문입니다.
- 계급은 이름표(`소대장 [대위]`)와 가죽→사슬→철→다이아 투구로 함께 표시됩니다. Polymer 가
  타워 본체 장비를 전달하지 않으므로 Queen 계열과 같은 공용 갑옷 거치대 오버레이를 사용합니다.
- 역할 장비는 본부의 나침반, 경계 계열의 철 투구·방패, 보병의 석궁, 포병의 TNT입니다.
- 시각 구분: 본부는 떠돌이 상인, 경계는 아이언 골렘, 전투는 약탈자(단일)와 마녀(광역)입니다.
  **모두 바닐라 엔티티여야 합니다.** `friendsandfoes:tuff_golem` 을 쓴 적이 있는데 서버가
  `Couldn't create template entity` 를 남기고 타워가 아예 보이지 않았습니다. 모드 엔티티는
  Polymer 패치를 거치는데 그 패치가 모든 타입을 덮지 않습니다
  (`ArmyTowerCatalogTest.everyTowerUsesAVanillaEntity` 가 이를 막습니다).
- 승진·지휘·포격·전역 범위 효과는 국방색(`#556B2F`)과 훈장색(`#D4AF37`) 팔레트를 사용합니다.

### 마왕

다른 빌더와 전제가 다릅니다. **타워는 하나도 싸우지 않습니다.** 제단 40종(스킬 10 × 티어 4)은 전부
피해 0, 사거리 0, 어그로 0이며 무적입니다. 제단이 하는 일은 플레이어 핫바에 스킬을 하나 얹는 것뿐이고,
레인을 지키는 것은 마왕 본인입니다.

- **코스트**: 기존 `towerSlotCost`(타워 수) 시스템을 그대로 씁니다. 스킬 10종의 합이 32라
  전부 열 수는 없습니다. 코스트는 티어가 올라도 그대로이고 업그레이드는 다이아만 먹습니다.
- **종류별 하나**: 같은 스킬의 제단은 하나만 세울 수 있습니다(`ProductionTowerService`에서 차단).
  더 강하게 쓰려면 업그레이드해야 합니다.
- **키 바인딩**: 스킬은 **먼저 지은 순서대로** 키에 배정됩니다. 첫 번째 제단이 `1`번입니다.

  | 순번 | 키 | 발동 |
  |---|---|---|
  | 1~4 | `1` `2` `3` `4` | 슬롯을 고르는 즉시 발동, 손은 마검으로 복귀 |
  | 5 | `5` | **손에 들고 우클릭**. 조준한 뒤 사용합니다. |
  | 6 | `F` | 오프핸드 교체 키를 가로챔 |
  | 7 | `Q` | 아이템 드롭 패킷을 가로챔 |

  키는 7개인데 스킬은 10종이라, **무엇을 들고 갈지가 곧 빌드**입니다. 여덟 번째 제단은 누를 키가
  없으므로 배치 단계에서 아예 막습니다. 아이템 이름에 `[1] 악의 파동`처럼 키가 붙고, 타워 정보창에도
  `코스트 3 · [1] 키`로 표시됩니다.
- **핫바**: 전투 중에는 핫바 전체가 마왕 전용입니다. 스킬과 **9번 슬롯의 마검**(네더라이트 검)만
  남습니다. **전투에서 벗어나면** 스킬을 걷고 평소 매치 도구(나침반·에코 샤드)를 돌려줍니다.
  타워를 사는 건 준비 단계이므로 도구가 필요한 시점과 스킬이 필요한 시점이 겹치지 않습니다.
  쿨타임은 엔더 진주와 같은 아이템 쿨다운 표시로 보이고, 인벤토리에서 옮겨도 1초마다 제자리로
  되돌아옵니다.
- **마검 평타**: 근접 평타가 됩니다. 바닐라 공격 경로를 취소하고 런타임 피해로 넣기 때문에
  공격 쿨다운·스윙 애니메이션·타격음을 직접 재현합니다. 차지가 꽉 찼으면 강타음, 아니면 약타음이라
  **소리로 타이밍을 알 수 있습니다**. 피해 배율은 바닐라와 같은 `0.2 + 차지² × 0.8` 곡선입니다.
- **전투 상태**: 웨이브가 시작되면 자기 레인 중앙으로 이동하고 비행이 막힙니다. 라운드 시작이
  아니라 웨이브 시작인 것이 중요합니다 — 준비 단계에 전투로 들어가면 핫바가 스킬로 덮여 타워를
  살 수 없습니다. 라운드가 끝나면 전투가 풀리고 준비 도구가 돌아옵니다.
  여기서 "중앙"은 `positionAt(0.5)`이 아닙니다. `pathPoints()`는 레인 스폰에서 시작해
  **공용 final_waypoint를 거쳐 중앙 boss_spawn까지** 이어지므로, 그 절반을 잡으면 레인 밖에
  떨어집니다. 자기 `lane_path` 영역 안에 들어오는 경로 구간만 골라 그 중간을 씁니다.
  자기 레인을 정리하기 전에는 그 레인 안에서만 싸울 수 있습니다. 정리하면 공용 최종 방어 구역
  중앙으로 이동하고, 이후 스킬과 이동 범위도 그 구역으로 제한됩니다. 최종 방어 몹은 정상 방어
  사거리 안에 도착한 뒤에만 마왕을 노리므로, 멀리서 어그로가 끌려 이동이 끊기지 않습니다.
  순간이동 계열은 벽 속이나 허공에 착지하지 못하게 `safeLanding`이 목표에서 시작점 쪽으로
  되짚어 실제로 설 수 있는 첫 지점을 고릅니다. 그래도 맵 아래로 빠지면 현재 전투 구역으로
  되돌립니다 — 전투 중에는 비행이 잠겨 있어 스스로 올라올 방법이 없습니다.
- **체력과 피격**: 보스바에 자기 체력이 뜹니다. 이 체력은 **바닐라 체력과 별개 풀**이라 실제로 죽거나
  아이템을 떨구지 않습니다. 대신 바닐라 피해를 막으면 연출도 사라지므로 `ClientboundHurtAnimationPacket`
  으로 붉은 화면과 피격 방향 카메라 기울기를 직접 보냅니다. 최대 체력의 5%를 넘는 타격에는 낮은
  피격음이 겹칩니다.
- **전투 제외**: 체력이 0이 되면 스킬을 못 쓰고 몹의 타깃에서도 빠지며 비행이 다시 열립니다.
  **다음 라운드 시작 시 최대 체력으로 부활**하고 쿨타임도 모두 초기화됩니다.
- **성장**: 몹을 처치하면 처치 대상 최대 체력에 비례해 경험치를 얻고, 레벨이 오르면 최대 체력과
  피해량이 함께 오릅니다(기본 450, 레벨당 +52.5 / 피해 레벨당 +5%, 만렙 30에서 2.45배).

  유지되므로 기본 체력은 사실상 1~2라운드에만 의미가 있습니다.

## 실제 노출 기준

카탈로그에 등록된 타워라도 선택한 빌더의 `canUseTower(...)`가 허용해야 플레이어가 설치할 수 있습니다. `/semiontd tower list`와 타워 UI는 현재 빌더가 사용할 수 있는 starter 타워만 보여줍니다.
