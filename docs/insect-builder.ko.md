# 벌레 빌더

> 핵심 컨셉과 유닛 역할은 [다섯 신규 빌더 컨셉 설명집](five-builders-player-guide.ko.md#벌레-빌더)을 참고하세요.

직업 ID는 `semion-td:insect_towers`입니다. 벌레는 첫 배치의 순간 화력과 스포너 주변의 반복 부활로 라인을 오래 붙잡습니다.

## 병과

| 역할 | 강화 경로 |
|---|---|
| 딜탱 | 좀벌레 → 엔더마이트 → 강화 엔더마이트 |
| 탱커 | 동굴거미 → 거미 → 강화 거미 |
| 원거리 | 벌 → 강화 벌 → 여왕벌 |
| 거점 | 스포너 |

새로 설치한 기본 전투 유닛은 준비 단계부터 최대 체력과 기본공격 피해가 1.75배가 되고 외형이 20% 커집니다. 설치 직후 상세창에도 `첫 배치 강화 활성`로 표시되며, 처음 참여하는 웨이브가 끝나면 수치와 크기가 정상으로 돌아옵니다. 이 웨이브를 끝내기 전에는 강화할 수 없습니다.

## 부활

전투 유닛이 죽은 위치 반경 6 안에 살아 있는 자기 <light_purple>스포너</light_purple>가 있으면 4초 뒤 <green>부활</green>합니다. 같은 라운드에 다시 죽을 때마다 대기시간은 3초씩 늘고 <red>받는 피해 증가</red>가 20%씩 쌓입니다.

부활 완료 전 연결된 스포너가 모두 파괴되거나 범위 밖에서 죽으면 영구 사망합니다. 최종 방어로 이동해도 연결은 유지되고 부활 지점만 최종 방어 슬롯으로 바뀝니다. 스포너가 여러 개 겹쳐도 속도와 횟수는 증가하지 않으며, 다음 라운드에는 사망 횟수와 약화가 초기화됩니다.

스포너를 설치하면 반경 6블록을 나타내는 원형 파티클이 나오며, 웨이브 중에는 4초마다 다시 표시됩니다.
스포너의 어그로는 벌보다 높고 좀벌레·거미보다 낮습니다.
