### 공통 지정 도구

기존 공통 지정형 증강과 대상을 직접 고르는 직업 증강에 같은 도구를 사용한다. 마을의 거신, 세계수, 우리 동네 대장과 사령왕은 직접 지정한다. 수석 졸업의 경험치 1위, 복제 공장의 투자액 1위와 거함 거포의 피해 기준 타워는 각 카드의 자동 선정 조건을 유지한다.

| 입력 | 동작 |
| --- | --- |
| 카드 클릭 | 증강을 획득하고 지정 도구를 받는다. 타워가 없어도 미지정으로 보관한다. |
| 도구를 들고 웅크린 채 우클릭 | 획득 순서대로 지정할 증강을 바꾼다. 아이템 이름과 액션바에 현재 증강을 표시한다. |
| 단일 대상 증강: 타워 좌클릭 또는 우클릭 | 해당 타워를 지정한다. |
| 영혼 결속: 타워 좌클릭 / 우클릭 | 좌클릭은 선봉, 우클릭은 포대다. 서로 다른 두 타워가 유효해야 효과를 적용한다. |
| 공중 우클릭 | 현재 증강의 대상을 해제한다. 영혼 결속은 두 역할을 함께 해제한다. |
| 도구를 들고 있기 | 현재 증강에 지정한 타워를 본인에게만 발광으로 표시한다. 전투 중에도 확인할 수 있다. |
| 도구를 내려놓기 | 지정 표시를 지운다. 다른 능력이 부여한 발광과 투명 상태는 보존한다. |

대상 지정, 변경, 해제는 준비 시간에만 허용한다. 잘못된 클릭은 기존 지정을 유지한다. 카드 마감 때는 기존 무작위 증강 지급을 유지하되 타워는 자동으로 고르지 않는다.

도구는 소모하지 않는다. 재접속과 재지급 때 하나만 유지하고, 인벤토리가 꽉 차면 기존 아이템을 덮어쓰거나 바닥에 떨어뜨리지 않는다. 빈칸을 만든 뒤 기존 증강 화면에서 다시 받을 수 있다.

승급과 일시 사망은 같은 논리 타워의 지정을 유지한다. 판매나 영구 제거는 미지정으로 남기며 대체 타워를 자동으로 고르지 않는다. 재지정은 획득 보상을 다시 지급하지 않고 체력 비율을 유지한다.

- 원맨쇼: 준비 시간에 주역을 바꿀 수 있다. 미지정이어도 다른 타워의 피해 감소는 유지한다.
- 고참병의 흉터: 다른 대상으로 변경하거나 해제하면 숙련을 초기화한다. A→B→A도 0부터 시작한다. 같은 타워 클릭과 정상 승급은 유지한다.
- 오버히트: 다음 준비 시간에 대상만 해제한다. 매 라운드 다시 클릭해야 사용하며, 실제 사용한 전투마다 해당 타워에 열화를 한 번 남긴다.
- 도구 입력은 타워 상세창, 개발자 복제 조작, 일반 공격보다 먼저 처리한다. 다른 도구의 기존 동작은 바꾸지 않는다.

| Q17 | 약탈, 열쇠공 | 만기 개봉만 발동한다. 약탈은 기본 상자 무료권 최대 1장, 라운드 첫 개봉에 지급한다. 열쇠공은 만기 보상만 +50%이며 기본 환급, 영구 성장, 뱃사공 수입을 유지한다. 기간 단축으로 연쇄 개봉해도 건별 지급과 첫 개봉 효과는 중복하지 않는다. |
| Q18 | 거함 | 전투 시작에 내 원본 공격 타워 중 현재 공격력 1위의 값을 고정한다. 2, 4, 6, 8, 10초에 전방 적을 다시 골라 반경 3블록, 최대 12기에게 각각 200% 물리 피해를 준다. 전투당 함포 1중첩 소비, 종료 후 남은 포격 취소, 임의 환불 없음. 최초 1중첩과 개봉 3회마다 200다이아 및 함포 획득은 유지한다. |
| Q19 | 비활성 직업, 유충 | 마법사, 벌레, 미래 기관까지 124개를 구현하고 시험하되 활성화 설정은 유지한다. 유충은 원본 최대 체력과 공격력의 40%로 생성하며 그 능력치를 기준으로 사망 폭발과 접촉 폭발을 계승한다. 유충 생성, 부활, 부활 거점은 계승하지 않는다. 기존 벌레 리워크를 보존한다. |

복제 공장은 플레이어당 라운드 추가 복제본 12기와 3세대를 함께 적용한다. 최초 복제본은 1세대이며 1세대와 2세대만 각각 한 번 증식한다. 예약도 횟수에 포함하고 사망으로 돌려주지 않는다. 추가 복제본도 즉시 합체하되 합체 재료별 증식 권리를 보존한다. 100짜리 두 기를 합쳤다면 80짜리 두 기, 다음 공격에 64짜리 두 기를 만든 것으로 계산하며 추가 생성은 총 4기다. 한 공격에서 다음 세대까지 재귀 생성하지 않는다.

### 이름과 오탈자

사용자가 정한 이름을 우선한다. `연쇄 폭발`은 J01-G2와 J18-P에서, `합동 공격`은 J13-S와 J13-G2에서 중복된다. 이름으로 저장하거나 효과를 찾지 않는다. 목록과 선택 기록에는 직업과 등급을 함께 보여 준다. `삼중 브레스`는 이름을 유지하고 수정본대로 2회 발사한다. 이름을 근거로 3회로 되돌리지 않는다.

전체 목록에서는 읽기만 방해하는 공백과 오탈자를 정리했다. `블럭 → 블록`, `대상 반격 → 대상 반경`, `표식이 세겨진 → 표식이 새겨진`, `부활 수 → 부활 후`, `병졍 → 병정`이다. Crowdin JSON에는 첨부 문구를 보존하고 위 다섯 확정 규칙만 수정했다. 수치가 모호한 `공격속도 30%` 등은 교정으로 확정하지 않았다.

## 4. 구현 순서와 완료 조건

### 단계 0. 규칙과 데이터 확정

Q 항목의 답을 카드별로 기록한다. 입력 JSON, 표시 문장, 구현 파라미터, 검토번호 대응을 대조한다. 이름 중복은 허용하되 ID 중복은 거절한다. 조커 기본 능력치와 포격 표적처럼 값이 없는 기능에 개발자가 임의 수치를 넣지 않는다.

완료 조건: 구현에 들어갈 카드의 대상, 발동 조건, 수치, 보관·초기화 시점과 실패 처리가 모두 정해져 있다. 나머지 카드는 기획에 남기고 후보에서 비활성으로 관리한다. 단계별 비활성은 기능 제외 결정이 아니다.

### 단계 1. 지정 도구, 직업 조건과 선택 흐름

공통 지정형 증강에 지정 도구와 본인 전용 지속 발광을 먼저 연결한다. 이후 직업 조건과 124개 정의를 기존 카탈로그에 연결한다. 정의 목록이 크면 직업 전용 목록만 별도 파일로 나눈다. 범용 효과 스크립트, 새 GUI, 별도 선택 상태 머신을 만들지 않는다.

완료 조건:

- 내 직업·등급·마일스톤에 맞는 카드만 제시하며, 미구현 카드와 비활성 직업 카드는 나오지 않는다.
- 최초 제안, 재추첨, 최종 적용, 시간 초과의 네 경로가 같은 조건을 검사한다. 낡은 후보와 재접속으로 다른 직업 카드를 얻지 않는다.
- 세 선택지와 안전한 예비 보상, 유효 재추첨 후보가 없을 때 횟수 미차감, 동일 요청 1회 적용을 유지한다.
- 지정형 카드는 대상 없이 획득한 뒤 도구로 지정한다. 명시적인 자동 조건은 유지한다. 일반 준비 25초와 별개인 증강 선택 60초 동안 에메랄드 생산 중단을 유지한다.
- 특성과 증강의 동시 사용을 유지한다. 직업 전용 증강 제한을 기존 공통 증강 제한으로 확대하지 않는다.

### 단계 2. 작은 효과 세 개로 전체 경로 검증

첫 묶음은 J08-S 흉조, J15-G1 라이벌 매치, J16-G2 폭발은 예술이다!다. 표식, 처치 성장, 지연 범위 공격을 기존 선택 흐름에 연결한다.

카드 정의부터 선택, 실제 효과, 개인 메시지 호버, 종료 정리, 카탈로그 표시까지 연결한다. 효과가 없는 카드부터 대량 등록해 공개하지 않는다.

완료 조건: 원래 빌더 효과와 추가 효과를 분리해 측정하고, 추가 공격의 재발동과 다음 경기 상태 유출이 없다. 테스트용 강제 제안은 기존 관리자·내부 시험 경로에서만 허용한다.

### 단계 3. 기존 능력 조정과 주기 공격

동물의 공동 공격, 공명, 습격, 네더 생존, 워든 소닉 붐, 용사 무기, 수면, 압력, 번개, 마왕 스킬, 심장 박동, 개발자 패치, 한기를 각 빌더의 현재 처리 경로에 연결한다. 아래 전체 목록의 직업별 구현 위치와 검증 항목을 작업 단위로 삼는다.

기본 공격은 시도·적중·실제 피해를 구분한다. 추가 공격이 공격 횟수를 올려 자신을 다시 발동하지 않게 한다. 기절 중 이동·공격·능력 차단을 유지하며, 쌓인 주기 공격을 해제 순간 몰아서 실행하지 않는다. 수면 중 공격 같은 명시적 예외는 수면만 우회한다.

완료 조건: 카드별 정상 발동과 경계 실패를 포함한 회귀 검사가 있다. 특정 카드의 새 경로가 기존 공통 피해·기절·보호막 계산을 우회하지 않는다.

### 단계 4. 성장, 결제, 개봉

주민 생존 성장, ADV 경험치와 +40% 승급 가격, 흡수 공유, 식물 성장 계승, 자동 전역, 도박, 상자 개봉을 2절의 확정 규칙대로 구현한다.

완료 조건:

- 실제 결제액만 투자·성장·판매가 기록에 들어간다. 무료 설치는 결제액 0이며 할인 전 가격으로 판매 이익을 만들지 않는다.
- 실패한 설치·승급과 롤백은 설치권·성장·함포를 소비하거나 지급하지 않는다.
- 상자 기간 단축으로 다른 상자가 즉시 열려도 개봉별 지급은 한 번, 라운드 첫 개봉 효과도 한 번이다. 경기 종료 뒤 지급하지 않는다.
- 성장 계승은 원본 성장 값으로 계산하고, 임시 전달 보너스를 다시 상속해 증식하지 않는다. 업그레이드에서 실제 성장과 증강 상태를 보존한다.

### 단계 5. 복제본, 조커, 부활과 규칙 변경

복제 공장과 합체, 쌍둥이 용, 조커 3기, 예비군, 생존자, 벌레 부활 거점을 구현한다. 생성 예약도 상한에 포함하고, 원본과 복제본의 능력치·수명·성장 상속 범위를 카드별로 고정한다.

복제 공장은 기존 생성 큐를 사용한다. 최초 복제본 n기의 한 번씩 증식과 세대 제한을 적용하면 추가 생성은 최대 `min(2n, 12)`기다. 최초 4기라면 추가 8기, 최초 8기라면 추가 12기가 상한이다. 기본 복제본을 포함한 총수 12기로 축소하지 않는다. 사망한 자식의 생성 횟수를 돌려주지 않는다. 자식의 능력치와 대상 본체 선정 시점은 Q08 답을 따른다.

조커는 배치권 3장을 즉시 지급하고 실제 배치는 기존 설치 경로에서 한다. 정상 설치만 권리를 소비한다. 카드 족보를 계산할 때 조커 값을 매번 최적화하되 실제 카드 ID를 무작위로 바꾸거나 추가 선택창을 띄우지 않는다.

완료 조건: 생성·공격·사망·판매·승급·최종 방어·재접속·경기 종료에서 유령 엔티티와 남은 생성 예약이 없다. 성능 때문에 승인된 12기, 3세대, 공격 동작을 줄여야 한다면 먼저 사용자에게 확인한다.

### 단계 6. 표시, 웹 호환, 시험과 공개 판단

선택 카드, 채팅 호버, 선택 기록과 웹 카탈로그에 같은 명칭과 설명을 사용한다. 숫자는 경기 설정에서 읽어 렌더링하고, 문구의 숫자와 실행값을 따로 하드코딩하지 않는다. Crowdin JSON은 문구 편집 입력이며 효과 실행 엔진이 아니다.

웹 후속 확인 위치는 `semion-web/lib/augment.mjs`, `lib/catalog.ts`, `tests/augment.test.mjs`, `tests/season3-sync.test.mjs`다. 직업 조건이 없는 구버전 카탈로그도 읽도록 한다. 원래 ID로 쌓인 통계는 명칭 변경으로 갈라지지 않아야 한다. 저장소가 새 선택 필드를 보존하는지 먼저 확인하고, DB 변경이 필요하면 그때 별도 계획과 승인을 받는다.

- 실제 클라이언트에서 추가 확정창 없음, 개인 호버, 지정 도구의 클릭과 발광, 복제 세대, 조커 족보 표시를 확인한다. 자동 검사와 화면 확인 결과를 따로 보고한다.

- 30명 접속 시험은 사용자 결정대로 제외한다. 라이브 밸런스가 입증됐다고 표현하지 않는다. 운영 배포·운영 설정 적용·후보 공개는 별도 승인 대상이다.

## 5. 전 카드 공통 구현 규칙

이 절은 승인 범위의 공통 구현 규칙이다. 카드별 차이는 2절의 확정표를 따른다. 새로운 게임 의미가 필요하면 먼저 사용자에게 묻는다.

- 상태는 직업 싱글턴이 아니라 플레이어·경기 또는 타워에 둔다. 타워 상태에는 기존 논리 ID와 상태 복사 경로를 사용한다.
- 공격/주기 카운터, 라운드당 사용량, 영구 성장, 설치권을 분리한다. 각각 초기화 시점을 적고 두 번째 경기에서 재사용 상태가 없는지 검사한다.
- 추가 피해는 공통 피해·범위 효과 경로를 사용한다. 물리·마법, 보호막, 처치 소유권, 통계와 기존 특성을 유지한다.
- 일반 추가 공격은 자기 증강의 횟수를 다시 올리지 않는다. 복제 공장의 세대 증식, 연쇄 폭발, 표식 전이 등 명시적 연쇄만 정해진 예산 안에서 허용한다. 무조건적인 ‘모든 재귀 금지’로 승인 효과를 없애지 않는다.
- 타워 제거 사유를 구분한다. 판매·승급·라운드 정리가 전투 사망, 개봉, 자동 전역을 대신 발동하지 않는다. 예외는 카드 문구와 Q 답에 명시한다.
- 준비 단계 진입을 전투 시작으로 쓰지 않는다. 웨이브 시작 수치 고정은 정상 경험치·성장·공명 적용 순서를 확인한 뒤 한 번만 한다.
- 자동 지정 결과와 충전량 등은 해당 플레이어에게 보여 준다. 상대와 전체 채팅에 타워 지정이나 매 라운드 선택 피드백을 방송하지 않는다.

기존 공통 지정형 증강에 도구를 연결했다. 카드를 누르면 대상을 고르지 않아도 획득한다. 도구는 단일 대상 좌클릭과 우클릭, 영혼 결속의 선봉과 포대 분리, 공중 우클릭 해제, 웅크린 우클릭 증강 전환을 처리한다. 소유자와 준비 단계, 대상 유효성을 서버에서 검사한다.

기존 개인 발광 패킷을 재사용했다. 도구를 든 동안 현재 지정 타워에 표시를 보내고 내려놓거나 타워를 제거하면 복원한다. 재접속과 재지급은 도구를 하나만 유지한다. 고참병의 흉터는 재지정과 해제 시 숙련을 초기화하며, 같은 타워 클릭과 승급은 보존한다. 체력 비율을 유지하는 기존 동기화 경로를 사용한다.

한 우클릭에서 엔티티 상호작용과 후속 아이템 사용 패킷이 함께 오는 경우는 기존 아이템 재사용 대기시간 2틱으로 묶었다. 지정 직후 후속 패킷이 대상을 해제하거나 증강을 두 번 전환하지 않도록 한다.

### 실행 근거와 남은 제한

- Java 21에서 `rtk ./gradlew test runGameTest remapJar --console=plain --no-daemon`을 실행했다. 마지막 실행은 유닛 테스트, GameTest와 JAR 생성을 모두 다시 수행했으며 40초에 성공했다.
- 제외된 유닛 테스트 2개는 `EndBalanceRepositoryContractTest`의 별도 밸런스 저장소 계약 검사다. 통과 수에 포함하지 않았다. 신청형 빌더 밸런스 시험도 실행하지 않았으므로 운영 밸런스가 검증됐다는 뜻은 아니다.
- 화면 확인 중 일반 준비 단계의 기본 도구 재지급이 증강 지정 도구를 지우는 문제를 발견했다. 공통 플레이어 배치 경로에서 현재 증강 상태로 도구를 복원하도록 수정했다. `targetToolSurvivesNextRoundAndRepeatedParticipantPlacement`가 실제 라운드 전환과 반복 복원에서 중복 지급·지정 유실을 검사하며 최종 전체 검사에 포함됐다.
- 화면 확인용 서버는 `127.0.0.1:25566`의 별도 월드·설정·DB를 사용했다. 해당 서버에서만 증강을 켜고 제안과 재화를 고정했다. 운영 설정이나 밸런스 측정 자료가 아니며 확인 후 종료했다.
- `copper-golem-vision-client-fabric-1-21-8`로 실제 화면을 추가 검수했다. [검수 기록](2026-09-21-season-3-builder-augment-client-qa.ko.md)에 장면별 근거와 시험 조건을 구분했다. PNG는 로컬 `build/s3-augment/client-qa-2026-09-21/`에 보관했다. 원본 로그, 시험 모듈, 임시 설정과 화면 자료는 커밋 대상에서 제외한다.
- 최종 로컬 JAR은 `build/libs/semion-td-1.0-SNAPSHOT+1.21.8.jar`다. 실제 마우스 선택·호버·도구 조작과 다른 플레이어 시점, 대표 사례 외의 개별 화면 확인은 남아 있다. 이번 추가 검수로 게임 코드를 바꾸지 않았으며 전체 자동 검사를 다시 실행하지 않았다. 자동 검사 성공은 공개 활성화나 운영 배포 승인을 대신하지 않는다.
