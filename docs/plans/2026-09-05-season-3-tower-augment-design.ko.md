# 세미온 TD 시즌 3 타워형 증강 추가 후보

> 기준일: 2026-09-05 · 브랜치: `s3-release` · 상태: 5장 모두 구현 범위로 승인. 수치는 내부 시험 시작값(H0)이며 공개 승인은 별도다.

선택 규칙과 서버 확정 절차는 [증강 시스템 명세](./2026-09-03-season-3-augment-design.ko.md)를 따른다. 이 문서의 5장은 기존 방벽, 박동 중계기, 방벽 핵심과 [거인 사냥꾼](./2026-09-05-season-3-augment-candidates-2.ko.md)과 함께 구현한다. 일반 후보 35장에 포함하지만 공개 풀은 기본 비활성이다.

## 1. 보상 방식과 공통 규칙

| 방식 | 선택하면 받는 것 | 배치할 때 필요한 것 |
|---|---|---|
| 설계도 | 해당 경기의 설치 목록에 새 타워를 추가한다. 무료 타워는 주지 않는다. | 표에 적힌 다이아, 빈 자리, 슬롯 |
| 호출 | 지정 타워의 무료 배치권 1장이다. 미사용 권리는 다음 준비 단계에도 남는다. | 빈 자리와 슬롯. 배치 성공 때만 권리를 소비한다. |

- 한 플레이어는 경기당 타워형 증강을 한 장만 고른다. 설계도 한 장으로 여러 기를 허용하는 경우에도 카드별 설치 한도를 지킨다. 다른 빌더로 바꾸거나 기존 타워를 판매할 필요는 없다.
- 이번 후보는 `SAFE=false`다. 제안 생성과 최종 확정 때 합법적인 첫 배치 위치와 슬롯을 확인한다. 설계도는 최소 한 기를 살 현재 다이아도 필요하다. 선택은 위치나 자원을 예약하지 않으므로 실제 배치 때 다시 검사한다.
- 유료 설계도 타워는 기존 준비 단계 판매와 실결제 기준 환급을 따른다. 무료 호출 타워는 판매·수동 재배치를 금지한다. 두 방식 모두 일반 승급과 복제를 허용하지 않는다. 별빛 고치의 자동 부화만 예외다.
- 전투 중 자력 이동은 하지 않는다. 시스템의 최종 방어 이동과 다음 라운드 복구는 따른다. 시스템 이동, 재접속과 엔티티 재생성은 탄약·진행도·사용 횟수를 새로 지급하지 않는다. 전투 중 파괴된 타워는 다음 라운드에 정상 복구한다.
- 새 타워는 외부 회복과 증강·빌더 전투 버프를 받지 않는다. 사망으로 긍정적인 타워 사망 효과를 만들지 않는다. 공격은 다른 증강·빌더의 공격 횟수나 적중 발동을 진행시키지 않는다. 적 처치의 정상 보상과 진행도는 기존 경로에서 한 번 처리한다.
- 공격 대상은 공용 전투 경로가 허용하는 적 몬스터다. 공격 범위 안이라는 이유만으로 아군, 빌더 프록시나 방어 보스를 공격하지 않는다. 피해 유형별 방어와 보호막을 정상 적용하며 방어 무시 피해를 추가하지 않는다.
- 저압 계약 유닛은 새 충전·적중 누적·포격·지뢰 발동 조건을 채우지 않는다. 이미 완성한 축전 충전은 강화 기본 공격으로 피해를 주고 소모한다. 공격 실패나 유효 체력 피해가 없는 타격에는 충전을 보존한다.
- 타워 지원 대상은 같은 소유자의 살아 있는 일반 영구 타워다. 직업 핵심, 증강 전용, 임시, 복제, 무적 타워는 제외한다. 거리 동률은 논리 ID 순으로 판정한다. 범위 경계는 포함하며 거리는 현재 전투 위치의 3차원 유클리드 거리다.
- 웨이브당 한도는 레인 전투와 최종 방어를 합친 한 라운드의 한도다. 명시한 초기화 외에 재충전하지 않는다. 20틱은 정상 20 TPS에서 게임 시간 1초다.

비공격 전용 타워만 허용했던 이전 제한은 폐기한다. 아래 응급 종탑은 비공격형이며, 나머지 네 장과 거인 사냥꾼은 승인된 공격형이다. 기본 공격이 없는 매복 작업장도 공격형으로 분류한다.

## 3. 카드 상세

### 3.1 응급 종탑 설계도

> 위급한 타워를 발견하면 종을 울려 회복합니다. 한 웨이브에 서로 다른 타워를 세 번까지 구합니다.

| 항목 | H0 |
|---|---|
| 타워 ID | `augment_emergency_bell` |
| 비용 / 체력 / 슬롯 | 120다이아 / 100 / 1칸 |
| 동시 설치 한도 / 지원 반경 | 1기 / 6블록 |
| 회복 | 대상 최대 체력의 25%, 한 번에 최대 90 |
| 확인 간격 / 사용 한도 | 20틱 / 웨이브당 3회, 같은 타워는 1회 |

- 발동: 확인 시점에 현재 체력이 최대 체력의 40% 이하인 지원 대상 중 체력 비율이 가장 낮은 한 기를 고른다. 살아 있는 타워만 회복한다. 유효 회복량이 0이면 횟수를 쓰지 않는다.
- 기록: 플레이어의 해당 라운드 상태에 사용 횟수와 회복한 논리 타워 ID를 남긴다. 타워 엔티티 교체나 최종 방어 이동으로 다시 회복하지 않는다. 다음 웨이브에 세 번을 새로 준비한다.
- 판단과 재미: 탱커 세 기가 차례로 구조받을 위치와 주력 딜러까지 범위에 넣는 위치를 비교한다. 한 기만 버티는 편성에서는 회복 한 번 뒤 남은 두 번을 쓰지 못할 수 있다.
- 약점: 기본 공격이 없으며 한 번에 죽는 타워를 살리지 못한다. 회복량과 횟수에 상한이 있어 지속 회복 빌더를 대신하지 않는다.
- 화면: 범위와 회복 예상량을 배치 전에 표시한다. 전투 중 `구조 2/3`, 종소리와 회복 대상을 보여 준다. 체력 200인 타워의 1회 회복은 50이며 총회복의 이론상 상한은 270이다.
- 비교 시험: 세 전열을 둔 편성과 단일 전열 편성을 비교한다. 수치가 회복됐다는 사실과 실제로 공격 시간을 벌었다는 결과를 구분한다.

### 3.2 축전 초소 설계도

> 적이 오지 않는 동안 전기를 모았다가 다음 한 발에 모두 쏟습니다.

| 항목 | H0 |
|---|---|
| 타워 ID | `augment_capacitor_post` |
| 비용 / 체력 / 슬롯 | 기당 140다이아 / 180 / 1칸 |
| 동시 설치 한도 / 사거리 | 2기 / 5블록 |
| 기본 공격 | 마법 피해 35, 간격 20틱 |
| 충전 | 적이 없는 상태 40틱마다 1개, 최대 3개 |
| 방출 | 다음 주 대상 기본 공격에 충전당 마법 피해 70 추가 |

- 발동: 전투 중 공용 타기팅으로 공격할 수 있는 적이 사거리 안에 없을 때만 충전 시간을 쌓는다. 적이 들어오면 미완성 시간은 지우고 완성된 충전은 남긴다. 준비 단계에는 충전하지 않는다.
- 방출: 유효 체력 피해를 주는 다음 주 대상 기본 공격에 충전을 모두 쓰며 하나의 공격으로 계산한다. 공격 실패에는 보존한다. 최대 충전탄은 방어 전 `35+70×3=245`다. 첫 탄부터 최대 충전으로 시작하지 않는다.
- 기록: 초소별 논리 상태에 충전과 미완성 시간을 저장한다. 웨이브 시작에만 0으로 초기화한다. 두 기를 지어도 충전을 공유하지 않는다.
- 판단과 재미: 앞쪽에서는 계속 사격하고, 뒤쪽에서는 기다렸다가 돌파해 온 적에게 큰 한 발을 쏜다. 초소 둘을 한곳에 모을지 교전 지점을 나눌지도 고른다.
- 약점·화면: 적이 끊이지 않으면 충전 효과를 쓰지 못한다. 이름표의 `충전 2/3`, 사거리 미리보기와 방출 번개로 대기와 공격의 차이를 보여 준다.
- 비교 시험: 같은 비용의 기존 공격 타워와 전방·후방 배치를 비교한다. 초기 발산안의 기본 피해 20/30틱, 최대 탄 110은 해금 카드와 설치 비용을 함께 내는 보상이 약할 우려가 있어 위 H0로 높였다. 높은 수치가 후방 요격의 재미를 보장하지는 않는다.

### 3.3 매복 작업장 설계도

> 작업장 앞에 지뢰 세 개를 준비합니다. 적이 밟으면 터지고 다음 웨이브에 다시 준비합니다.

| 항목 | H0 |
|---|---|
| 타워 ID | `augment_ambush_workshop` |
| 비용 / 체력 / 슬롯 | 220다이아 / 180 / 1칸 |
| 동시 설치 한도 | 1기 |
| 지뢰 위치 | 설치 위치에서 레인 출입구 방향으로 2·4·6블록 |
| 기폭 / 피해 반경 | 1.25블록 / 2블록 |
| 폭발 | 물리 피해 100, 가까운 적 최대 2기, 지뢰당 1회 |

- 배치: 플레이어는 작업장 위치만 고른다. 방향은 고정된 몬스터 경로의 첫 수평 진행 방향과 반대다. 길이가 0이거나 수직으로만 움직이는 구간은 건너뛰고, 처음 수평 변위가 있는 구간의 XZ 벡터를 정규화한 뒤 반대로 향하게 한다. 대각선·회전 경로에도 같은 규칙을 적용하며 작업장 위치에서 입구를 향한 벡터는 쓰지 않는다. 수평 구간이 없으면 배치할 수 없고 이유를 표시한다. 설치 때 이 방향의 2·4·6블록 수평 상대 좌표를 확정하고 각 지점의 지면 높이를 확인한다. 세 지점을 준비 단계에 표시하며, 셋 모두 레인 전투 영역 안의 합법적인 지상 위치여야 설치할 수 있다. 새 방향 선택창이나 지뢰별 편집 화면은 만들지 않는다.
- 발동: 공용 범위 조회로 5틱마다 확인한다. 아직 이 작업장의 지뢰에 맞지 않은 적이 기폭 반경에 들어오면 폭발한다. 피해 대상에서도 이미 맞은 논리 몬스터 ID를 제외한다. 후보가 없으면 지뢰를 소비하지 않는다. 유효 후보에게 시도한 폭발은 보호막으로 막혀도 소비한다.
- 한도: 같은 적에게는 웨이브당 한 번만 지뢰 피해를 시도한다. 설치 때의 2→4→6블록 순번으로 지뢰를 처리한다. 각 지뢰는 폭발 중심에서 가까운 적부터 고르고, 선택한 대상 ID를 기록한 뒤 다음 지뢰를 처리한다. 세 지뢰의 합계 상한은 6대상·방어 전 600피해다. 지뢰는 별도 개체가 아니며 슬롯, 길막과 자체 처치 보상을 만들지 않는다.
- 생명주기: 작업장이 파괴되면 남은 지뢰를 해제한다. 다음 웨이브에 세 개를 재장전한다. 최종 방어 이동 때 이전 지점은 해제하고 미사용 지뢰의 수평 상대 좌표만 새 타워 위치에 더한다. 방향을 다시 계산하거나 회전시키지 않는다. 지면 높이와 유효성을 다시 확인해 유효하지 않은 지뢰는 비활성화하며 사용 기록은 유지한다.
- 판단과 재미: 기존 전열 앞에 두어 첫 교전에서 적을 줄일지, 뒤에 두어 돌파병을 처리할지 정한다. 한 적이 세 지뢰를 모두 소모하는 상황은 막되, 적이 밟지 않는 곳에 설치한 손해는 남긴다.
- 약점·화면: 기본 공격이 없고 세 번 터지면 해당 웨이브의 화력을 다 쓴다. 지점 표식, `지뢰 2/3`과 실제 명중 수를 표시한다. 공중 적은 기폭·폭발 대상에서 제외한다.
- 비교 시험: 위치를 바꾸면 명중 대상이 달라지는지 본다. 합법적인 세 지점을 확보하기 어렵거나 지뢰를 밟는 이유를 알 수 없다면 사선·지형 편집 기능을 늘리지 말고 후보를 보류한다.

### 3.4 별빛 고치 호출

> 고치를 두 웨이브 지키면 같은 자리에서 별빛 파수꾼이 깨어납니다.

| 항목 | H0 |
|---|---|
| 타워 ID / 보상 | `augment_starlight_cocoon` / 무료 배치권 1장 |
| 슬롯 / 총 배치 한도 | 고치 때부터 2칸 / 경기 중 1기 |
| 고치 | 체력 260, 공격 없음 |
| 부화 조건 | 파괴되지 않고 끝낸 웨이브 누적 2회 |
| 파수꾼 | 체력 600, 사거리 5, 단일 마법 피해 110, 간격 30틱 |

- 진행: 웨이브 시작부터 배치돼 있고 레인 전투와 최종 방어를 끝낼 때까지 파괴되지 않아야 1회를 얻는다. 파괴된 웨이브는 세지 않고 이전 진행도는 보존한다. 탈락·경기 종료는 부화 성공으로 세지 않는다.
- 부화: 두 번째 성공 뒤 실제 다음 준비 단계가 열리면 같은 논리 타워를 파수꾼 상태로 한 번 전환한다. 정상 라운드 회복 뒤 새 최대 체력 600으로 시작한다. 별도 소환이나 두 번째 타워 배치가 아니며 슬롯은 계속 2칸이다.
- 위치·기록: 논리 타워의 원래 배치 위치와 시스템 이동 규칙을 보존한다. 라운드 정산 ID와 진행도, 부화 여부를 저장해 재접속으로 성공 횟수를 늘리지 않는다. 추가 승급이나 무한 스택은 없다.
- 판단과 재미: 안전하게 부화시킬 위치와 부화 뒤 적을 공격할 위치를 함께 고른다. 두 슬롯을 당장 쓸 전투 타워에 투자하는 선택과 비교한다. 기존 성장 타워의 스택은 건드리지 않는다.
- 약점·화면: 고치 상태에서는 두 슬롯을 쓰면서 공격하지 못한다. 파수꾼도 단일 대상만 공격한다. `부화 1/2`, 부화 후 능력치와 외형 변화를 보여 준다. 두 웨이브를 더 버틸 수 있다는 보장은 하지 않는다.
- 비교 시험: 안전한 구석에서는 부화하지만 공격에 참여하지 못하고, 전투 위치에서는 보호가 필요한 구도가 생기는지 본다. 무료 체력 260을 가진 탱커로만 쓰거나 부화 직후에도 기존 두 슬롯보다 체감이 약하면 조건과 보상을 재검토한다.

### 3.5 군수공장 호출

> 공격형 인컴을 구매하면 군수공장이 포탄을 준비해 다음 전투의 적 무리를 포격합니다.

| 항목 | H0 |
|---|---|
| 타워 ID / 보상 | `augment_ordnance_factory` / 무료 배치권 1장 |
| 체력 / 슬롯 / 총 배치 한도 | 300 / 1칸 / 경기 중 1기 |
| 기본 공격 | 물리 피해 20, 사거리 8, 간격 20틱 |
| 포탄 적립 | 적격 인컴 실결제 100에메랄드마다 1발, 웨이브당 최대 4발 |
| 포격 | 주 대상 위치 반경 3, 주 대상을 포함해 최대 5기, 추가 물리 피해 120 |
| 발사 간격 | 첫 정상 공격에서 1발, 이후 실제 발사부터 최소 100틱 |

- 제안: R15·R25에만 제시한다. 현재 100에메랄드 이상을 보유하고 정상 공격형 인컴을 구매할 수 있어야 한다. 초반 웨이브에 최대 4발을 더하는 R5안은 보류한다.
- 적립: 공장을 배치한 뒤 같은 준비 단계에서 최종 성공한 `NORMAL_PAID` 표준 공격형 인컴 거래의 실결제 에메랄드만 합산한다. 이후 라운드에는 준비 시작부터 집계한다. 표준 공격형은 별도 전투 능력 없이 체력과 기본 공격으로 싸우는 인컴이다.
- 제외: 실패·환불, 전투 중 구매, 예약 소환, 유틸, 보스, 무료 소환과 메아리는 적립하지 않는다. 다른 인컴 계약을 적용한 구매도 제외해 가격 보정과 보상 중첩을 피한다. 거래 ID를 한 번만 합산하며 `포탄=min(4,floor(적격 실결제 누계/100))`로 해당 전투의 초기 탄수를 정한다.
- 발사: 주 대상에게 유효 체력 피해를 준 기본 공격이 있고 탄과 발사 간격 조건을 만족하면 1발을 쓴다. 기본 공격 직전 대상 위치를 저장해 포격 중심으로 사용한다. 주 대상이 살아 있으면 우선 포함하고 나머지는 거리 순으로 고른다. 포격은 기본 공격이나 다른 포격을 재발동하지 않는다. 공격 공백이 길어도 밀린 탄을 한꺼번에 쏘지 않는다.
- 기록: 정산한 거래, 실결제 누계, 남은 탄과 마지막 실제 발사 시점을 보존한다. 최종 방어 이동에서는 유지하며 웨이브 종료 때 잔여 탄과 적립 잔액을 지운다. 이후 준비 단계로 넘겨 100을 채우지 않는다.
- 판단과 재미: 에메랄드를 생산력에 투자할지 공격형 인컴 구매에 써서 상대 압박과 자기 방어를 함께 준비할지 고른다. 인컴 가격과 정상 영구 인컴 증가량은 유지한다. 포탄에 별도 100에메랄드를 내는 카드가 아니다.
- 약점·화면: 인컴을 사지 않으면 기본 공격만 한다. `적격 구매 250 / 준비 포탄 2/4 / 잔여 50은 이월 안 됨`과 발사 후 남은 탄을 표시한다. 유틸 중심 운영은 포탄을 적립하지 못한다.
- 비교 시험: 포격 추가 피해의 상한은 단일 대상 480, 5대상 2,400이며 방어·보호막·초과 피해 전 값이다. R15·R25의 실효 피해를 나눠 측정한다. 정상 인컴 구매만으로 강한 무료 화력을 얻으므로 추가 경제 손실이 있는 카드처럼 평가하지 않는다.

## 4. 재미와 타당성 검토

[MDA 원문](https://cdn.aaai.org/Workshops/2004/WS-04-04/WS04-04-001.pdf)의 규칙·행동·경험 연결을 다음처럼 시험한다. 이 표는 기대하는 경험이며 재미를 입증한 결과는 아니다.

| 규칙 | 플레이어 행동 | 확인할 경험 |
|---|---|---|
| 대상별 한 번만 구조 | 종탑 범위 안에 전열을 분산한다. | 서로 다른 타워가 살아남는 안도감 |
| 적이 없을 때 축전 | 전방 사격과 후방 요격의 위치를 비교한다. | 기다린 한 발의 타격감 |
| 세 지점에 제한된 지뢰 | 전열과 지뢰의 교전 위치를 맞춘다. | 예상한 경로에서 매복이 성공하는 만족 |
| 두 웨이브 뒤 부화 | 슬롯과 보호 위치를 미리 투자한다. | 키운 전용 타워가 깨어나는 기대와 보상 |
| 인컴 구매에 포탄 지급 | 공격형 인컴과 생산 투자의 순서를 고른다. | 상대 공격 준비가 자기 방어로도 이어지는 조합 발견 |

Riot은 전용 유닛에 일찍 접근하는 보상 자체가 큰 전력을 차지하면 고유 효과의 재미에 쓸 여지가 줄어든다고 회고했다. 이번 호출형도 무료 몸체의 체력·공격력과 부화·포격의 가치를 따로 평가한다. [TFT: Into the Arcane Learnings](https://teamfighttactics.leagueoflegends.com/en-us/news/dev/dev-tft-into-the-arcane-learnings/)

활성 `tower_balance.json`에서 비교 단위를 확인했다. `t3_ranged_skeleton_tower`는 배치비 200, 체력 120, 피해 35/12틱이고 `t3_golem_tower`는 배치비 350, 체력 400, 피해 10/20틱이다. 공격만 놓으면 각각 약 58.3·10 DPS지만 빌더 고유 능력과 승급 경로를 제외한 수치다. 새 타워의 밸런스가 적절하다는 근거로 쓰지 않는다. 설정 경로는 `/Users/qf/Desktop/semionTD/config/semion-td/tower_balance.json`이며 이번 작업에서 라이브 경기 지표를 새로 집계하지 않았다.

첫 비교 시험에서는 같은 빌더, 총 투자 예산, 슬롯과 웨이브를 고정한다. 설계도는 카드 한 장과 유료 설치비를 함께 지불한 보상으로 비교한다. 호출형은 무료 배치비뿐 아니라 다른 프리즘 한 장을 포기한 기회비용과 슬롯을 포함한다. 효과를 알아본 장면과 다음에 바꿀 배치를 묻고, 수치가 높아도 선택 뒤 판단이 같다면 후보를 줄인다.

## 5. 서버 구현 경계와 검증 순서

- 설치 목록과 실제 배치 권한은 기존 명세 10.5절의 `availability=AUGMENT`와 `ProductionTowerService` 경계를 따른다. 무료 호출, 두 기 설치 한도와 웹 소유권 때문에 별도 플레이어별 카탈로그를 만들지 않는다.
- `SupportTower.execute`, `AllayTower`의 회복·대상별 제한과 공용 범위 조회를 종탑의 출발점으로 삼는다. 회복 전용이라고 선언하는 것만으로 일반 공격이 사라지는 것은 아니므로 비공격 실행을 검증한다. 축전 초소와 공장은 일반 공격 경로를 쓰고, 지뢰·포격은 공용 범위 피해와 정상 귀속을 사용한다.
- 기존 `TowerDataKey`와 라운드 상태를 재사용한다. 고치 부화는 논리 ID·슬롯·위치를 보존하는 1회 상태 전환이며 판매·배치·사망 보상을 호출하지 않는다. 실제 별도 피해 결과가 있는 중계기·지뢰·포탄은 특수 피해도 기록한다. 특수 피해는 총피해에 이미 포함되므로 다시 합산하지 않는다. 하나의 기본 공격으로 합산되는 거인 사냥꾼·축전 추가량을 실측 기여처럼 추정하지 않는다.
- 기존 Dialog와 타워 상세에 비용, 배치 한도, 준비 상태를 표시한다. 사거리·지뢰 지점·부화 외형과 전투 피드백은 서버의 기존 VFX 경로로 표현한다. 새 지형 편집 GUI나 클라이언트 모드를 요구하지 않는다. 실제 클라이언트 표시 검증은 별도다.
- 먼저 응급 종탑과 축전 초소를 강제 제안으로 비교한다. 다음에 고치의 지연 보상을 확인한다. 매복 작업장은 합법적 배치와 최종 방어 이동을, 군수공장은 성공 거래와 포격 중복 방지를 확인한 뒤 시험한다.

문서 단계에서는 카드 수, 링크, 수치 예시와 제한의 일관성을 검사한다. 구현 단계에서는 재접속, 배치 실패, 승급·엔티티 교체, 파괴·복구, 같은 라운드 재정산, 최종 방어 이동과 복수 플레이어 간 격리를 시험한다. 문서 검사를 GameTest·서버 성능·클라이언트 표시·재미 검증의 통과로 보고하지 않는다.
