# 세미온 TD 도전과제 후보

> 상태: 핵심 도전과제 12개는 구현 완료. 일반 13~40번과 빌더별 항목은 기획 후보입니다.

바닐라 도전과제 화면에 표시할 세미온 TD 전용 후보입니다. 일반 도전과제 40개와 빌더별 도전과제 250개, 총 290개를 정리합니다. 튜토리얼 완료, 첫 설치, 첫 승리처럼 플레이만 하면 열리는 항목은 제외했습니다.

## 판정 원칙

- 샌드박스, 튜토리얼, 관리자 조작 경기는 집계하지 않습니다.
- 상대 팀에 실제 플레이어가 있는 정상 경기만 집계합니다.
- **완막**은 해당 라운드에 자신의 라인을 벗어난 몬스터가 없고 방어선도 무너지지 않은 상태를 뜻합니다.
- **모든 라운드**는 1라운드부터 경기 종료까지를 뜻합니다. 중도 참가자는 달성할 수 없습니다.
- 팀 조건은 경기 종료 시점의 모든 팀원을 대상으로 판정합니다.
- 수치가 없는 빌더 고유 조건은 도전과제 구현 때 전용 계측을 추가합니다.
- 경기 흐름을 망칠 수 있는 과제는 숨김 처리하고, 보상은 칭호와 코스메틱을 우선합니다.

## 일반 도전과제 선정 근거

일반 도전과제는 현재 게임이 집계하거나 저장하는 데이터만 사용합니다.

- 경기 결과: 승패, 최종 라운드, 팀별 탈락 라운드, 팀 인원, 시도 라운드, 완막 라운드
- 경기 통계: 처치, 다이아 획득, 수입, 소환 수, 인컴 위협, 방어 실패 위협, 지원 처치
- 행동 기록: 타워 설치·업그레이드·판매, 인컴 소환 대상 팀·라인, 에메랄드 생산 업그레이드
- 최종 조합: 타워 종류, 단계, 수량
- 누적 기록: 정상 경기 참가 수, 플레이한 빌더, 빌더별 승리

2026년 8월 20일 라이브 데이터 207경기에서 최대 3,728킬, 보낸 인컴 위협 340,163, 인컴 소환 463기, 최종 수입 5,093을 확인했습니다. 15라운드 팀 탈락은 82회, 40라운드 진입은 5경기, 로우맨 팀 승리는 18회 기록됐습니다. 한 플레이어의 최다 참가 기록은 130경기입니다.

타워별 처치·피해·체력, 준비 종료 직전 시간처럼 현재 집계하지 않는 값은 일반 목록에서 제외했습니다. `클러치`, `그니까... 이걸 막으라고요? 제가요?`, `큰거 한방 갑니다.`, `오 럭키`는 라운드 종료 때 이미 집계하는 완막 여부, 위협 증가량, 인컴 대상 라인을 사용합니다.
