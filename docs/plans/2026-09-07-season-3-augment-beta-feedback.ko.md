# 시즌 3 베타 증강 개선안과 1차 수치 상향

기준일: 2026-09-07. 작업 브랜치: `s3-release`.

## 최신 적용: 스탠스 분리와 이름·설명 정리

스탠스를 바꾸던 카드 5종을 고정 효과 카드 10종으로 분리했다. 일반 후보는 **40종**(실버 12·골드 17·프리즘 11), 예비 보상까지 **49종**이다. 전용 타워는 9종으로 유지한다. 새 카드의 수치와 불이익은 분리 전과 같다.

| 기존 카드 | 새 선택지 | 선택 방법 |
|---|---|---|
| 교전 계획 | 속전 / 지구전 | 원하는 카드 클릭으로 획득. 이후 스탠스 변경 불가 |
| 편향 장갑 | 물리장갑 / 마법장갑 | 원하는 카드 클릭으로 획득. 이후 방어 유형 변경 불가 |
| 전술 지명 I·II·III | 각 등급의 돌격 / 엄호 | 카드와 타워를 고르면 획득. 다음 준비 단계에는 타워만 변경 가능 |

같은 계열의 중복 선택과 카드 간 충돌 제한은 유지한다. 같은 제안에 속전과 지구전을 함께 내지 않으며, 한쪽을 얻으면 이후에도 반대쪽은 나오지 않는다. 물리장갑·마법장갑과 전술 지명 계열도 같다.

타워형 카드도 위 이름을 그대로 표시한다. 설계도·호출은 이름에서 빼고, 설명에 설치 비용이나 무료 배치권을 표시한다. 공성 전차의 이름 변경은 광역 포격 구현을 뜻하지 않는다. 기존 단일 대상 공격을 유지한다.

설명은 `조건 → 효과·수치` 순서로 쓴다. 예: “웨이브 시작에 반경 4블록 안에 이웃 타워가 없는 일반 영구 공격 타워는 최종 피해 +30%, 받는 피해 15% 감소.” 당연한 정산·유지 안내는 빼고 복제 유닛은 ‘복제본’으로 통일했다. 비용, 불이익, 중첩 상한, 영혼 결속의 파괴 시 해제 조건은 남긴다. `stop-slop`과 한국어 문법 기준으로 다듬었다.

[최신 증강 CSV](../exports/season-3-augments-2026-09-07.csv)에 분리된 선택지와 이름, 효과, 전용 타워의 T1·T2·T3 수치를 반영했다. 기존 설정 키와 명시된 값은 유지한다. 과거 통합 카드 ID는 읽을 수 있지만 새 후보·웹 카탈로그에는 내보내지 않는다. 게임 내 설명과 웹 카탈로그가 같은 설정값을 사용한다.

라이브 적용과 실제 클라이언트 화면 확인은 하지 않았다. 자동 검증 결과는 [구현·검증 기록](./2026-09-05-season-3-implementation-status.ko.md)에 남긴다. 아래는 이름 변경·카드 분리 이전의 1차 상향 기록이며 당시 명칭과 개수를 유지한다.

## 1차 상향 기록

기존 일반 증강 35종 중 34종의 수치를 상향했다. 비상 융자와 예비 보상 9종은 유지한다. 공성포형 개편, 신규 능력치 증강과 화면 개선은 아래에 기획안으로 남긴다. 코드에 적용한 수치와 후속 제안을 구분한다.

라이브 서버, 설정, DB는 변경하지 않는다. 아래 상향은 로컬 코드와 배포용 기본 JSON에만 반영한다. 기존 서버는 설정에 저장한 값을 계속 사용하므로 기존 키의 수치 상향은 JAR 교체만으로 적용되지 않는다. 새로 추가한 방벽 피해 상한은 3.4절을 따른다.

## 1. 피드백과 이번 작업의 범위

| 사용자 피드백 | 대응 | 이번 상태 |
|---|---|---|
| 설명이 어렵고 길다 | 효과 한 줄과 비용·불이익 한 줄을 먼저 표시하고 상세 규칙은 마우스 설명으로 제공 | 문구 원칙 작성. 실제 선택 화면 구성 변경은 후속 작업 |
| 타워형 증강이 약하다 | 기존 역할의 피해량, 회복량과 체력을 상향 | 전용 타워 9종 상향 |
| 거인 사냥꾼이 공성 전차처럼 느껴지지 않는다 | 단일 대상 저격을 광역 포격으로 개편 | 기획안만 작성. 현재 공격 방식 유지 |
| 선택 채팅에서도 설명을 보고 싶다 | 증강 이름에 효과 설명 연결 | 기획안만 작성 |
| 특성보다 약하고 선택 후 변화가 작다 | 조건 충족 보상을 늘리고 특성을 고정한 상태에서 비교 | 기존 증강 34종 수치 상향 |
| 고민 없이 고를 카드가 필요하다 | 조건 없는 능력치 증강과 한 칸 보장 규칙 추가 | 기획안만 작성. 후보 수와 추첨 규칙 유지 |

공식 명칭을 구분한다. **전술 지명**은 타워 하나에 돌격 또는 엄호를 지정하는 증강이다. **교전 계획**은 속전 또는 지구전으로 전투 시간대에 따른 강화를 고르는 증강이다. 사용자 피드백의 ‘거인 파괴자’는 현재 카탈로그의 **거인 사냥꾼 호출**을 가리킨다.

## 2. 확인한 근거와 한계

2026-09-07 조회 시점의 현재 카탈로그는 `ed4abfeb3fd737c10f78814798a622e6a61322d0556aa5f272161a60a3ecf4bc`다. 이 버전의 `NORMAL` 기록은 2경기, 참여 기록 40건이다. 두 경기의 전체 구간은 2026-09-06 20:11~21:50 KST다. 참여 기록 40건을 서로 다른 사용자 40명의 독립 표본으로 세지 않는다.

- 확인 경로: `/api/v1/stats`, `/api/v1/patches`, 전체 페이지를 조회한 `/api/v1/participant-metrics`.
- 현재 버전과 `NORMAL`만 남겼다. 전체 228경기를 합쳐 이번 증강의 성능 근거로 쓰지 않았다.
- 라이브 `augment_balance.json`의 카드별 수치는 변경 전 번들 기본값과 같았다. 라이브의 활성 설정은 둘 다 `true`, 번들은 둘 다 `false`다. 이 차이는 유지한다.
- 특성, 빌더, 투자액을 통제한 증강별 비교 결과는 없다. 이번 수치는 플레이테스트 피드백과 효과 구조를 근거로 정한 시험값이다. 운영 밸런스가 입증됐다는 뜻은 아니다.

현재 거인 사냥꾼은 3초 간격의 단일 대상 공격이며 최소 사거리가 3블록이다. 최대 체력이 높은 적을 우선하지만 광역 폭발은 없다. 기존 타워 성장도 이 공격 방식을 바꾸지 않는다.

라이엇은 증강을 설계할 때 숙련이 필요한 선택지와 ‘엄청나게 이로운 효과!’처럼 사용하기 쉬운 선택지를 함께 구성한다고 설명한다. 전투의 직관성과 눈에 보이는 위력도 검토한다. 세미온에서는 조건 없는 카드와 역할이 분명한 전용 타워를 함께 제공하는 데 이 기준을 적용한다. [TFT 게임 분석 팀의 설계 기준](https://teamfighttactics.leagueoflegends.com/ko-kr/news/dev/talking-tactics-game-analysis-team-gat/)

## 3. 기존 증강 수치 상향

이 절은 이번 코드에 반영한 값이다. `+35%`는 기존 피해에 35%를 더한다는 뜻이다. `×1.65`는 기존 수치의 1.65배다. 방어 수치는 별도 표시가 없으면 받는 피해 감소율이다.

대상 수, 적용 대상, 발동 조건, 재사용 대기시간과 기존 비용·불이익은 유지한다. 범위나 공격 횟수를 늘리지 않는다. 같은 계열의 중복 선택과 카드 간 충돌 제한도 유지한다.

### 3.1 일반·조건·대가형

| 증강 | 변경 전 | 변경 후 |
|---|---|---|
| 전술 지명 I / II / III | 돌격 피해 +15 / 25 / 40%, 엄호 감소 12 / 20 / 30% | 돌격 피해 **+35 / 65 / 100%**, 엄호 감소 **20 / 30 / 40%** |
| 삼각 진형 | 피해 +8%, 감소 8% | 피해 **+20%**, 감소 **15%** |
| 교전 계획 | 속전 피해 +18%. 지구전 피해 +10%, 감소 10% | 속전 피해 **+35%**. 지구전 피해 **+25%**, 감소 **15%** |
| 쌍둥이 편대 | 피해 +10% | 피해 **+30%** |
| 과열 코어 | 예약 타워 피해 +40% | 예약 타워 피해 **+100%** |
| 전열 분업 | 선봉 감소 30%, 포대 피해 +30% | 선봉 감소 **45%**, 포대 피해 **+70%** |
| 전장 숙련 | 생존 성공당 피해·최대 체력 +4%, 최대 +16% | 성공당 **+15%**, 최대 **+60%** |
| 편향 장갑 | 선택한 유형 피해 ×0.75 | 선택한 유형 피해 **×0.55** |
| 마무리 사격 I / II / III | 피해 +20 / 35 / 55% | 피해 **+40 / 70 / 110%** |
| 독립 진지 | 피해 +12%, 감소 8% | 피해 **+30%**, 감소 **15%** |
| 연승 포화 | 충전한 기본 공격 피해 +30% | 충전한 기본 공격 피해 **+60%** |
| 도미노 사격 | 초과 피해 60% 전달, 원래 피해 50%가 상한 | 초과 피해 **90%** 전달, 원래 피해 **75%**가 상한 |
| 원맨쇼 | 주역 피해 +100%, 최대 체력 +30% | 주역 피해 **+175%**, 최대 체력 **+60%** |

전술 지명은 돌격과 엄호 중 하나만 적용한다. 전장 숙련은 기존 피해 조건을 충족하고 살아남아야 쌓인다. 과열 코어의 열화, 전열 분업의 공격·방어 불이익, 편향 장갑의 반대 유형 피해 ×1.35, 원맨쇼의 다른 타워 피해 20% 감소는 그대로다.

### 3.2 인컴·경제형

| 증강 | 변경 전 | 변경 후 |
|---|---|---|
| 추가 적재 | 유틸 인컴 체력·지원량 ×1.35 | **×1.65**. 구매 가격 ×1.25 유지 |
| 예고 공세 | 복제본 능력치 비율 30% | **50%** |
| 지원 실적 | 성공당 정기 인컴 +2, 경기 합계 최대 +8 | 성공당 **+6**, 경기 합계 최대 **+24** |
| 현금 결제 | 포기한 인컴 증가량의 3배를 다이아로 지급 | **5배** |
| 금지된 설계도 | 승급권 한 장당 최대 300다이아 지원 | 최대 **450다이아**. 두 장 지급 유지 |
| 저압 고수익 | 추가 인컴 +25%, 라운드 보너스 최대 12 | **+40%**, 라운드 보너스 최대 **20** |
| 결전 납품 | 인컴 유닛 체력 ×1.6, 기본 공격 ×1.4 | 체력 **×2**, 기본 공격 **×1.8** |
| 전시 경제 | 일반 타워 피해 +35%, 최대 체력 +20% | 피해 **+65%**, 최대 체력 **+40%** |

금지된 설계도는 이용권 사용마다 이후 정기 지급액에 ×0.9를 적용한다. 저압 고수익은 유닛 체력과 공격 ×0.7, 현금 결제와 결전 납품은 해당 구매의 인컴 증가 포기, 전시 경제는 이후 정기 지급액 ×0.65를 유지한다. 지원 실적의 서로 다른 대상 세 기, 준비 단계당 한 번 조건도 유지한다.

비상 융자는 유지한다. 대출 상한을 높이면 상환 부담도 늘어 이득만 상향할 수 없다. 이자나 상환 규칙을 바꾸는 개편은 따로 결정한다. 후보 부족용 예비 보상 9종도 유지한다.

타워 설치 비용, 무료 배치권 여부와 자리 사용량은 바꾸지 않는다. 외부 회복·전투 강화 제외 규칙도 유지한다. 따라서 이번 상향만으로 타워형의 사용감 문제가 해결됐다고 판단하지 않는다. 거인 사냥꾼의 광역 포격은 아직 구현하지 않았다.

### 3.4 추가 요청: 접이식 방벽의 피해 상한

접이식 방벽에 **한 번에 받는 피해 최대 15 · 회복 불가**를 적용한다. 3.3절의 체력 상향과 함께 적용하며, 다른 타워에는 이 상한을 주지 않는다.

- 물리·마법·고정 피해와 전가 피해를 건별로 최대 15까지 받는다. 원래 피해가 7이면 7을 받는다. 여러 적에게 맞으면 각각 계산한다.
- 아군 회복, 자기 회복과 직접 회복을 받지 않는다. 남은 체력이 15 이하라면 다음 공격으로 죽을 수 있다.
- 라운드 종료 후 기본 복구와 R15·R25의 최대 체력 성장은 유지한다. T2·T3에서도 피해 상한은 15다.
- 설치 비용 160다이아, 한 슬롯, 최대 한 기와 기존 공격 대상 우선 규칙을 유지한다.

기존 증강 설정의 `folding_barricade_blueprint.damagePerHitCap` 기본값은 15다. 해당 키가 없는 구버전 설정을 읽으면 15를 채우고, 명시한 값은 보존한다. 이 새 규칙은 이후 JAR 적용 시 누락 키의 기본값으로 동작할 수 있다. 이번 작업에서는 서버 JAR이나 설정을 바꾸지 않는다.

## 4. 후속 기획: 설명과 채팅

### 선택 화면

첫 화면에는 효과 한 줄과 주요 비용·불이익 한 줄을 표시한다. 피해량, 적용 대상과 지속 조건을 먼저 쓴다. 효과를 얻기 위해 필요한 설치 비용이나 되돌릴 수 없는 불이익은 마우스 설명에만 숨기지 않는다.

전술 지명 I의 예시:

> 타워 하나를 골라 피해량 +35% 또는 받는 피해 20% 감소.\
> 준비 시간에 타워와 강화 방식을 바꿀 수 있습니다.

교전 계획의 예시:

> 속전: 전투 첫 8초 동안 피해량 +35%.\
> 지구전: 8초 뒤부터 피해량 +25%, 받는 피해 15% 감소.

상세 설명에는 중복 규칙, 적용되지 않는 대상, 판매·승급 시 처리를 둔다. 실제 수치는 해당 경기의 설정에서 읽는다. 이번에는 고정 카탈로그 요약에서 이전 수치를 제거했으며, Dialog와 웹의 상세 설명은 기존 설정 기반 표시를 유지한다. 선택 화면 전체를 두 줄 요약으로 바꾸는 작업은 별도다.

### 선택 채팅

`○○님이 [거인 사냥꾼 호출] 선택`에서 증강 이름에 마우스를 올리면 효과와 주요 제약을 보여준다. 기존 서버 채팅 기능을 사용한다. 다른 플레이어에게는 증강의 공통 설명만 보여주고 선택한 대상, 모드, 예약 내역은 공개하지 않는다. 매 라운드 설정 변경 알림도 되살리지 않는다.

## 5. 후속 기획: 거인 사냥꾼의 공성포형 개편

목표는 적 무리를 한 발로 쓰러뜨리는 장거리 포격 타워다. 별도 공성 모드 버튼 없이 배치 후 자동으로 공격하도록 제안한다.

- 느린 발사 간격과 근접 사각지대를 유지한다. 앞에서 버티는 아군 타워가 필요하다.
- 직격 대상 주변에도 고정 광역 피해를 준다. 최대 체력 비례 추가 피해는 직격 대상에만 적용한다.
- 밀집한 적을 노리는 목표 선정과 기존 최대 체력 우선 규칙 중 무엇을 쓸지는 구현 전에 결정한다. 현재는 최대 체력 우선이다.
- R15와 R25에 포탄 피해와 폭발 범위를 함께 늘린다.
- 포탄 궤적, 발사음과 폭발을 구분해 어느 타워가 적을 처치했는지 보여준다.

공격 방식과 정체성을 바꾸는 작업이므로 수치 상향에 섞어 구현하지 않는다. 범위, 피해 분배와 목표 선정 규칙을 확정한 뒤 진행한다.

## 6. 후속 기획: 조건 없는 능력치 증강

아래 수치는 제안값이며 이번 카탈로그에 추가하지 않았다.

| 계열 | 실버 | 골드 | 프리즘 |
|---|---:|---:|---:|
| 화력 지원: 타워 피해량 증가 | +20% | +35% | +60% |
| 강철 군단: 타워 최대 체력 증가 | +30% | +55% | +90% |
| 기본이 최고: 타워 피해량과 최대 체력 증가 | 각각 +10% | 각각 +20% | 각각 +35% |

대상 지정, 배치 조건이나 추가 비용 없이 선택 즉시 적용한다. 유효 후보가 있다면 세 선택지 중 한 칸은 이런 카드로 보장하는 규칙을 제안한다. 기존 `SAFE`는 안전하게 적용할 수 있다는 분류이며 ‘추가 조작이 없다’는 뜻은 아니므로 같은 것으로 취급하지 않는다.

적용 대상은 구현 전에 정한다. 기존 일반 타워 강화에서 제외하는 고유 핵심 타워와 증강 전용 타워를 새 카드에 포함할지 결정해야 한다. 이 범위를 정하지 않은 채 ‘모든 타워’라고 설명하지 않는다. 새 계열을 추가하면 일반 후보 수가 바뀌므로 기존 카드 교체 여부도 함께 결정한다.

조건형은 조건을 갖춘 편성에서 같은 등급의 능력치 카드보다 큰 이득을 주도록 검토한다. 신규 복합 능력치 카드가 공격형·방어형을 모두 밀어내지 않는지도 비교한다.

## 7. 구현 위치와 설정 적용

- `augment/AugmentConfig.java`: 카드별 기본 수치.
- `semiontd/balance-defaults/augment_balance.json`: 같은 수치를 넣은 배포용 기본 설정.
- `tower/augment/AugmentTowers.java`, `semiontd/balance-defaults/tower_balance.json`: 접이식 방벽과 방벽 핵심의 체력.
- `augment/AugmentCatalog.java`: 고정 요약의 오래된 수치를 제거. 실제 수치 설명은 `AugmentDescriptions`를 사용한다.

설정 구조와 ID를 유지한다. 기존 설정에서 명시한 값은 보존하고 빠진 항목만 기본값으로 채운다. 증강 설정 해시에 변경된 값이 포함되며 경기 시작 시 고정한 설정은 바꾸지 않는다.

운영 적용을 승인받으면 현재 서버 설정을 기준으로 3절의 해당 키만 수정한다. 번들 JSON을 파일 전체로 덮어쓰면 활성 설정이나 다른 사용자 조정값을 잃을 수 있으므로 그렇게 적용하지 않는다. 이번 작업에서는 적용 명령을 실행하지 않는다.

## 8. 검증과 다음 비교

자동 검사에서는 Java 기본값과 번들 JSON 일치, 구버전 명시 값 보존, 설정 해시 변화, 새 수치의 피해·회복·정산과 중복 방지를 확인한다. 공격 대상, 피해 유형, 추가 피해 재발동 방지와 타워 성장 검사는 유지한다. 결과는 [구현·검증 기록](./2026-09-05-season-3-implementation-status.ko.md)에 남긴다.

후속 전투 비교는 특성, 빌더, 투자액, 배치와 웨이브를 고정한다. 기존 수치와 상향 수치를 R5, R15, R16, R25에서 비교하고 처치 시간, 누수, 타워 사망과 유효 회복량을 확인한다. 경제형은 선택 직후의 전투뿐 아니라 이후 지급과 재투자까지 봐야 한다. 이번 작업에서 이 전투 비교나 실제 클라이언트 관찰을 완료한 것으로 기록하지 않는다.

플레이테스트에서는 ‘설명을 읽고 무엇이 좋아지는지 말할 수 있는가’, ‘선택 뒤 전투에서 변화를 알아볼 수 있는가’를 묻는다. 이 문서에서는 특성이나 웨이브를 함께 강화하지 않는다.

피해·회복이 중복 적용되거나, 실패한 구매에서 보상을 받거나, 경기 종료 뒤 보상을 받는 회귀가 나타나면 해당 변경의 공개를 보류한다. 특정 조합이 나머지 선택지를 밀어내는 현상은 같은 조건으로 재현한 뒤 카드별로 재조정한다. 일괄 하향이나 자동 롤백 비율은 정하지 않는다.
