# 직업 전용 증강 클라이언트 검수

검수일: 2026-09-21. 대상: `s3-release`의 현재 작업 트리.

Minecraft 1.21.8 실제 클라이언트에서 증강 제안·획득 기록, 지정 타워의 발광, 대표 복제·연사·부활 장면을 확인했다. 124종 전체의 화면 검수가 끝났다는 뜻은 아니다. 실제 마우스 클릭과 호버, 다른 플레이어 시점은 확인하지 못했다.

## 시험 환경과 방법

- `copper-golem-vision-client-fabric-1-21-8`로 실제 화면을 촬영했다. 카메라와 화면 관찰은 클라이언트 도구, 게임 상태 조작은 Copper Golem 서버 도구로 수행했다.
- Java 21, Fabric 1.21.8, 로컬 서버 `127.0.0.1:25566`을 사용했다. 월드·설정·DB는 운영 서버와 분리했다. 실제 클라이언트 1명과 가상 참가자 3명으로 NORMAL 경기를 만들었다.
- 로컬에서만 증강과 후보 풀을 켰다. 제안 등급·후보와 재화를 고정했으며, 자연스럽게 R5에 도달한 경기를 재현한 것은 아니다.
- 카드 획득은 실제 `AugmentService.handle`에 유효한 제안 정보를 전달했다. 타워 지정은 실제 `handleTargetToolInput`을 호출했다. 서버 처리와 화면 반영을 확인한 것이며, 마우스 입력 성공으로 판정하지 않는다.
- 전투 장면은 별도 로컬 시험 모듈로 준비했다. 실제 타워·증강 설정·피해·부활·시각 효과 경로를 호출하되, AI와 중력을 멈추고 표적을 고정했다. 복제·연사는 저속 촬영과 수동 레인 틱, 부활의 최종 촬영은 20 TPS와 수동 레인 틱을 사용했다. 자연 전투의 시간·밸런스 측정과 구분한다.
- 시험 모듈은 `build/s3-augment/` 아래에만 두었다. 배포용 JAR에 넣지 않았으며, 이번 검수로 게임 코드나 운영 설정을 바꾸지 않았다.

### 추가 검토할 점

쌍둥이 용은 원본과 복제본이 같은 위치에 생성됐다. AI를 멈춘 이번 장면에서는 겹쳐 보여 복제본을 구분하기 어려웠다. 정상 이동 중에도 문제가 지속되는지는 확인하지 않았으므로, 이동 전투에서 가독성을 다시 확인할 항목으로 남긴다. 생성 위치·크기·표시 방식은 이번 검수에서 임의로 바꾸지 않았다.

아래 항목은 미확인이다.

- 실제 마우스로 카드 선택, 설명 호버, 도구 좌·우클릭과 웅크리기 조합.
- 두 번째 실제 클라이언트에서 지정 발광이 보이지 않는지 확인.
- 나머지 카드의 개별 화면, 대표 사례 외의 복제·연사·부활 조합, 실제 조작을 포함한 재접속 흐름.

## 자동 검사와 작업 범위

이 검수에 앞서 2026-09-21 14:44:34 KST에 Java 21 전체 검사가 성공했다. 유닛 테스트는 1,310개 통과·기존 비활성 2개 제외, GameTest는 668개 통과, `remapJar` 성공이다. 이번에는 로컬 화면 시험 모듈을 컴파일하고 대표 장면을 실행했으며, 게임 코드 변경이 없어 전체 검사를 다시 실행하지 않았다.

검수 후 경기를 종료하고 가상 참가자 3명을 제거했다. 월드 저장을 확인한 뒤 시험 서버와 클라이언트를 종료했으며, 시험용 포트 `25566`·`8089`·`8101`의 리스너가 남지 않은 것을 확인했다.

운영 서버·DB, 공개 후보와 직업 활성화 설정, 웨이브 수치는 변경하지 않았다. 커밋·푸시와 30명 접속 시험도 하지 않았다. 결과는 화면 검수이며 운영 밸런스나 배포 승인을 뜻하지 않는다.

## 후속 수정: 선택창 상단 안내 축약

사용자 요청으로 선택창 상단을 선택 수·리롤, 즉시 획득, 지정 도구 안내의 3줄로 줄였다. 선택 마감, 생산 중단, 미선택 처리, 일반 준비 25초와 `/증강` 재열기 안내는 상단에서 제거했다. 선택 시간과 실제 지급·생산 동작은 바꾸지 않았다.

Java 21에서 문구 회귀 테스트와 전체 검사를 실행했다. 2026-09-21 20:46:59 KST 전체 검사 성공: 유닛 테스트 1,311개 통과·기존 비활성 2개 제외, GameTest 668개 통과, `remapJar` 성공. 격리 서버의 실제 1.21.8 클라이언트에서 3줄 안내와 카드 표시를 확인했다. 근거는 [28-compact-offer-header.png](../../build/s3-augment/client-qa-2026-09-21/28-compact-offer-header.png)다. 실제 마우스 입력은 이번에도 검사하지 않았다.
