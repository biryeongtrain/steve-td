# 기술자 빌더

> 핵심 컨셉과 유닛 역할은 [다섯 신규 빌더 컨셉 설명집](five-builders-player-guide.ko.md#기술자-빌더)을 참고하세요.

직업 ID는 `semion-td:engineer_towers`입니다. 기술자는 직접 공격하지 않고 실제 바닐라 레드스톤 회로와 함정으로 라인을 지킵니다.

## 플레이 흐름

1. 구리 골렘과 발판을 설치합니다.
2. 발판에서 함정까지 15다이아 레드스톤 가루 또는 중계기로 회로를 연결합니다.
3. 웨이브가 시작되면 구리 골렘이 `금 → 철 → 돌 → 나무` 순으로 발판을 찾아갑니다.
4. 전력을 받은 함정은 신호가 끊겨도 3초간 작동합니다. 작동 중 새 신호가 들어오면 남은 시간이 다시 3초가 됩니다.

구리 골렘은 웨이브 시작과 동시에 움직이고 발판 중앙까지 실제로 올라간 뒤에만 작동 완료로 판정합니다. 발판을 밟으면 전기 파티클이 나타나며, 더 갈 수 있는 발판이 없으면 마지막 발판 위에서 기다립니다. 같은 발판 위에 계속 서 있는 동안에는 새 신호로 재발동하지 않습니다.
함정이 전력을 받으면 붉은색·청록색 전력 VFX가 표시되고 이름이 `활성화된 <함정 이름>`으로 바뀝니다. 작동 VFX는 1초, TNT 점화 VFX는 0.5초 간격으로 제한됩니다.

구리 골렘·레드스톤 가루·중계기는 타워 슬롯을 사용하지 않습니다. 발판과 함정은 하나씩 사용합니다. 구리 골렘은 플레이어당 한 기만 설치할 수 있습니다.
레드스톤 가루와 중계기는 합쳐 최대 35개이며, 현재 사용량은 화면 위 보스바에 표시됩니다.
발판은 플레이어당 최대 4개이며, 나무 발판으로 설치한 뒤 `나무 → 돌 → 철 → 금` 순으로 강화합니다. 실제 레드스톤과 발판 블록을 우클릭하면 논리 타워 상세창이 열리지만 레드스톤 위에는 이름표가 나타나지 않습니다.
피스톤은 플레이어당 최대 3개만 설치할 수 있습니다. 함정은 최근 3초 안에 구리 골렘이 누른 연결 발판이 있어야만 작동하므로 무한 반복 회로로 재발동할 수 없습니다. 중계기는 바라보는 방향으로만 신호 거리를 전달합니다.

## 함정

| 함정 | 역할 |
|---|---|
| 문 | 위아래 두 칸짜리 철문으로 표시되며, 작동 중 주변 몬스터를 유인합니다. 파괴되면 다음 라운드에 복구됩니다. |
| TNT | 3초 점화 후 물리 범위 피해를 주며 라운드당 한 번 폭발합니다. |
| 발사기 | 진행도가 가장 높은 적을 반복 사격합니다. 발판까지의 회로 거리 1칸당 피해가 10% 증가하며 최대 10칸까지 적용됩니다. |
| 피스톤 | 일반 라인 몬스터를 라인 시작점으로 되돌립니다. 같은 몬스터는 15초 면역을 얻습니다. |
| 슬라임 | 범위 내 일반 라인 몬스터의 이동속도를 단계에 따라 30%·42%·55% 낮춥니다. |

강제 최종방어가 시작되면 구리 골렘과 모든 회로·함정은 즉시 정지합니다.
